# Documentation screenshots

Captured for Curatorr v0.1.100 on 27 September 2026 in Chrome. Images show the application's content area, without the browser address bar. All ten images from the previous set have been recaptured, with additional views for newer features.

The images use the actual v0.1.100 application running in the isolated [documentation demo](../../scripts/demo/README.md), with the built-in **Hide scrollbars** appearance option enabled. Album names, track names, and covers come from public MusicBrainz and Cover Art Archive data. Listener identities, listening history, playlists, preferences, analysis values, and service status are synthetic. Other themes, roles, and primary media servers can change the available controls.

No production data, private instance addresses, contact details, tokens, or personal avatars are used. Service forms contain reserved example addresses. Music Assistant connection results and listener mappings are simulated fixtures, not evidence of a live integration test. Cover artwork remains the property of its respective rights holders.

Legacy filenames retained to avoid breaking image links:

- `curatorr-dashboard.png` now shows **Overview**.
- `curatorr-discover-added-for-you.png` now shows **Artist Pipeline**, replacing the retired Added For You layout.
- `curatorr-user-profile.png` shows personal appearance controls, keeping account contact details out of the image.

The repository's wiki publishing script copies image files into the wiki's `media/` directory. This README is capture documentation for maintainers and is not copied as a wiki page.
