# Curatorr v0.1.44

## Summary

- **Analyzer worker scripts now ship with the release source** — the analyzer-sidecar Python scripts are no longer excluded by `.gitignore`, so GitHub Actions tag builds can actually copy them into the analyzer image.
- **Analyzer Docker build repaired** — the `curatorr-analyzer` image no longer fails during `COPY scripts/...` when publishing from a release tag.
- **Multi-arch analyzer publishing retained** — the analyzer image still publishes for both `linux/amd64` and `linux/arm64`, preserving the `v0.1.43` release workflow fix.

## Fixed

- Fixed `.gitignore` excluding the entire `scripts/` directory, which prevented analyzer worker files from being included in release tags.
- Fixed analyzer image builds failing from tagged GitHub Actions checkouts because `scripts/analyze-track-features.py` and `scripts/analyzer-sidecar.py` were absent from the repository tree.
- Fixed release packaging so the analyzer Dockerfile inputs now exist in the Git checkout used by Docker Buildx.

## Upgrade Notes

- Publish `v0.1.44` or later if you need the analyzer sidecar image to build successfully from GitHub Actions tags.
- `v0.1.43` contains the workflow fix but can still fail during analyzer image build if the tag was created before the analyzer scripts were committed.
