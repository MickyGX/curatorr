# Curatorr v0.1.29

## Summary

- **Blend page and shared listening workflow** — Curatorr now includes a dedicated Blend page with a compatibility-ranked user carousel, playlist-style artwork cards, and live shared artist/track results so users can explore how well their listening overlaps before building something together.
- **Blended smart playlists** — smart playlists can now be generated from two or more users, making it possible to build shared playlists from combined taste instead of a single listener profile.
- **Plex setup wizard reliability** — the server setup wizard can now fetch and store the Plex server token directly from a Plex owner sign-in flow, then continue setup without forcing users to paste a token manually.
- **User wizard Plex bootstrap fixes** — when the admin skipped the Plex token during setup, the user wizard now backfills the stored Plex connection on first load, refreshes the master track cache, and populates genres/artists correctly instead of landing on an empty selection step.
- **Plex playback tracking fix** — repeated plays of the same Plex track are no longer collapsed into a single finalised event, improving artist and track scoring accuracy.
- **Lidarr request hardening** — Lidarr artist-list requests now handle abort/timeout errors safely and use a longer timeout for large libraries, avoiding the `Cannot set property code of which has only a getter` failure.

## Upgrade Notes

- No database migration required. Drop-in replacement for v0.1.28.
- Rebuild the container after updating so the wizard, webhook, and Lidarr request fixes are included in the running image.
