# Curatorr v0.1.19

## Summary

- **Last.fm Station Playlist fix** — the Recommended, Mix, and Library playlists introduced in v0.1.18 were silently failing to create or update in Plex due to an incorrect argument being passed internally when resolving the Plex server identifier. Playlists now sync correctly on every Smart Playlist Sync run for users with station toggles enabled.

## Upgrade Notes

- No database migrations, no config changes. Drop-in replacement for v0.1.18.
