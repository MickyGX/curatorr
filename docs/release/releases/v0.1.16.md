# Curatorr v0.1.16

## Summary

- Added `LOCAL_AUTH_MIN_PASSWORD` environment variable to allow configurable minimum password length for local Curatorr accounts. Default remains `12`. Capped between `1` and `128`. Intended for local network installs where a strict password policy is not required.
- Added startup warning logged to console if `LOCAL_AUTH_MIN_PASSWORD` is set below `12` and `TRUST_PROXY` or `COOKIE_SECURE` is also enabled, indicating the instance may be internet-facing.

## Upgrade Notes

- No database changes. Rebuild and redeploy to include the new environment variable support.
- The default password policy is unchanged — existing installs are unaffected unless `LOCAL_AUTH_MIN_PASSWORD` is explicitly set.
- If you are running behind a reverse proxy (`TRUST_PROXY=true`) or HTTPS (`COOKIE_SECURE=true`), do not lower `LOCAL_AUTH_MIN_PASSWORD` below `12`. Curatorr will warn in docker logs if this combination is detected.
