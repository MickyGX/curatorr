# Curatorr v0.1.9 Announcement

Curatorr `v0.1.9` is out.

## Highlights

- Playlists now use a card-carousel workflow with inline rebuild actions and a more capable sortable track table.
- Tracks, Artists, and History now share the same compact artwork-aware table style and sorting behavior.
- Dashboard and Discovery layouts were refreshed, including better carousel handling, recommendation presentation, and mobile overflow fixes.
