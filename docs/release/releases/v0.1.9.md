# Curatorr v0.1.9

## Summary

- Reworked the playlist experience around a card carousel with inline rebuild actions, background full-playlist loading, and a sortable track table that still defaults to showing the current visible slice.
- Unified playlists, tracks, artists, and history onto the same compact media-table pattern with artwork-aware album and artist columns, sortable headers, and consistent filtering controls.
- Refreshed dashboard and discovery layouts with playlist and active-stream carousels, tighter panel controls, improved recommendation presentation, and more reliable mobile overflow handling.
- Improved discovery artwork loading so recommendation cards can use cached or fallback art paths without slowing the page on repeated upstream image fetches.

## Upgrade Notes

- Rebuild and redeploy Curatorr so the updated playlist, tracks, artists, history, dashboard, and discovery assets are included in the running image.
- Do a hard refresh after upgrade so the new shared UI assets (`panel-controls.js`, `filter-popovers.js`, and the latest stylesheet version) replace older cached files.
