# Curatorr Release Announcement

Curatorr `0.1.40` is out.

Highlights:

- **New Curatorr rotating playlist** — Curatorr now includes a new configurable rotating playlist that blends familiar favourites with discovery tracks.
- **Daily Mix controls** — Daily Mix can now be tuned directly from Settings with controls for source mix, total size, per-artist caps, cooldowns, and filters.
- **Unified rotating playlist sync** — Daily Mix and Curatorr now rebuild and sync through the same generated-playlist flow, with matching wizard, settings, and playlist-page support.
