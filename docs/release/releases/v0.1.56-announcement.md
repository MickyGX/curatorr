# Curatorr Release Announcement

Curatorr `0.1.56` is out.

Highlights:

- **Startup time fixed** — the app was taking 30+ seconds to start on NAS hardware because every log entry triggered a synchronous 239 KB disk write. Startup is now near-instant.
- **General sluggishness fixed** — the same synchronous write was happening on every log-generating request during normal use. Page loads will feel dramatically faster.
- **Playlist track images load near-instantly** — album and artist thumbnails are now cached server-side for an hour, cutting ~200 redundant Plex image fetches per playlist page load down to zero on repeat visits within the same session.
