# Curatorr Release Announcement

Curatorr `0.1.56` is out.

Highlights:

- **Playlist track images load near-instantly** — album and artist thumbnails are now cached server-side for an hour, cutting ~200 redundant Plex image fetches per playlist page load down to zero on repeat visits within the same session.
- **Faster container restarts on large libraries** — two startup migration queries that scanned entire tables on every restart are now skipped when no rows need updating.
- **Version check is now timeout-safe** — the Docker Hub latest-release lookup won't hang the UI on NAS hardware with limited outbound connectivity.
