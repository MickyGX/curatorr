# Curatorr Release Announcement

Curatorr `0.1.41` is out.

Highlights:

- **Analyzer sidecar and automatic feature enrichment** — Curatorr can now build its own BPM/key/Camelot/energy/danceability dataset using the new Docker-friendly analyzer sidecar or a custom external analyzer command.
- **Feature presets for playlists** — global and personal playlists now have visual preset cards, Camelot targeting, and live match counts while you tune the feature ranges.
- **Better feature correctness** — feature presets now exclude tracks without the required analysis data instead of counting missing values as zero.
- **Shared enrichment layer** — MusicBrainz dates, local analysis output, and Plex loudness now feed the same track enrichment store for filtering and sequencing.
