# Curatorr Release Announcement

Curatorr `0.1.36` is out.

## Highlights

- **ListenBrainz reliability** — playlist suggestion sync now logs failures more clearly and includes a fallback request path for Docker/container setups where Node networking behaves differently from direct command-line requests.
- **Better Jellyfin admin flow** — Jellyfin now has a more complete settings and webhook-management experience inside Curatorr.
- **More playlist tooling** — smart-playlist and global-playlist management continue to get richer filtering and preview controls in Settings.
