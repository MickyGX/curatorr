# Curatorr v0.1.45

## Summary

- **CI lockfile repaired** — the committed `package-lock.json` now matches `package.json`, so GitHub Actions can run `npm ci` again.
- **Release packaging remains fixed** — analyzer worker scripts stay tracked in Git, which keeps the analyzer image build working from release tags.
- **Multi-arch analyzer publishing remains enabled** — `mickygx/curatorr-analyzer` continues publishing for both `linux/amd64` and `linux/arm64`.

## Fixed

- Fixed the committed npm lockfile so CI no longer fails during `Install dependencies`.
- Preserved the analyzer-sidecar release fixes introduced in `v0.1.44`, including tracked worker scripts and valid Docker build inputs for tag builds.

## Upgrade Notes

- Use `v0.1.45` or later if you want both a passing `checks` workflow and a working analyzer Docker publish workflow from the same release tag.
