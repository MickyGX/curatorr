# Curatorr v0.1.30

## Summary

- **Plex Home login-loop fix** — Curatorr now stores only the minimal pending Plex Home profile data needed during sign-in, which keeps the cookie-backed session under browser limits and prevents the post-auth redirect from falling back to `/login`.
- **Blend page shell fix** — the Blend page now loads the same shared dashboard scripts as the rest of Curatorr, restoring the animated music-note background, user-pill pop-up menu, sidebar controls, and other shared shell behavior.

## Upgrade Notes

- No database migration required. Drop-in replacement for v0.1.29.
- Rebuild and redeploy the container so the updated Plex auth flow and Blend page shell are included in the running image.
- If the Blend page still shows the old shell after upgrade, do a hard refresh once so the browser picks up the new page assets.
