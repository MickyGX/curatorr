# Curatorr Release Announcement

Curatorr `0.1.87` is out.

## Highlights

- **New Music Mix** - a new smart playlist starting point for recent library additions, with album variety controls built in.
- **Release-aware playlists** - filter by release year, release date, and rolling release windows to separate recently added music from genuinely new releases.
- **Better media-server metadata** - Plex, Jellyfin, and Emby master refreshes now populate added-to-library timestamps for smart playlist rules.
