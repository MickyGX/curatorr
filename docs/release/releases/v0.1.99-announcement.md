# Curatorr v0.1.99 Announcement

Curatorr `v0.1.99` fixes playlist imports choosing songs by the wrong artist, and fixes the play count on the Overview Now Playing card.

## Highlights

- **No more wrong-artist import matches**: Spotify, Last.fm, ListenBrainz, and M3U imports no longer swap in a cover or unrelated song with the same title. Every listed artist is now checked.
- **Correct Now Playing play count**: the card shows plays for the track you're listening to, or "First play" for a new one.
- **Jellyfin and Emby artwork fixed**: Now Playing album art loads again, with a music icon fallback.
