# Curatorr v0.1.103

## Summary

This release adds TIDAL as a playlist import source and fixes local password changes and local user creation, which were failing with an HTTP 500 error.

## Added

- **TIDAL account connection**: users can connect their own TIDAL account from **User Profile**. Sign-in uses TIDAL's official developer API with OAuth and PKCE.
- **TIDAL import tab**: **Playlists → Import playlist → TIDAL** lists playlists owned by the connected account, with search and a preview of matched, unmatched, and duplicate tracks.
- **TIDAL URL import**: TIDAL playlist links and IDs are recognised in the URL tab. Public playlists can be imported without connecting an account.
- Imported TIDAL playlists match against the library with the same matcher as other imports. They support manual and scheduled refresh, and include a **View on TIDAL** link. Only tracks are imported; videos in a TIDAL playlist are skipped.

## Fixed

- Fixed changing a local account password from **User Profile** failing with an HTTP 500 error and the log message `crypto.randomBytes is not a function` ([#173](https://github.com/MickyGX/curatorr/issues/173)). Adding local users from **Settings → Users** failed the same way and is also fixed. Passwords and users were not changed by the failed requests.
- Added regression tests for local password changes, local user creation, the TIDAL client, and TIDAL account connection and import.

## Upgrade Notes

- Update the Curatorr app image and recreate the container as usual. New TIDAL connection columns are added to the database automatically on startup. No analyzer update is required.
- TIDAL import is optional. To enable it, create an app in the [TIDAL Developer Dashboard](https://developer.tidal.com/dashboard) with the `playlists.read` and `user.read` scopes. Add the redirect URI `<your Curatorr base URL>/user-settings/tidal/callback`, then set `TIDAL_CLIENT_ID` and `TIDAL_CLIENT_SECRET` on the container.
- Optionally set `TIDAL_COUNTRY_CODE` (default `US`) to choose the catalog region used for public playlist links read without a connected account.
- Setup details: `docs/wiki/Integrations.md#tidal`.
