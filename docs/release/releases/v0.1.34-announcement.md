# Curatorr Release Announcement

Curatorr `0.1.34` is out.

## Highlights

- **Discovery album controls** — manual discovery album cards and Curatorr picks now support playlist-style select, view, and add actions, plus richer album overview modals with track lists and ordered fallback albums.
- **Playlist control improvements** — global playlists can now be edited from Settings and the Playlists page, and Crescive / Curative generated playlists can be toggled independently.
- **Playback and webhook reliability fixes** — recent-play consolidation is more resilient across pause/resume and metadata variations, the dashboard now mirrors rolled history, and Plex webhook re-registration cleans up stale Curatorr webhook URLs automatically.
