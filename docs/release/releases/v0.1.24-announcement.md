# Curatorr v0.1.24 Announcement

Curatorr `v0.1.24` is out.

## Highlights

- **Admin users page** — new admin-only user overview page with avatars, roles, listening stats, playlists, Lidarr additions, and recent activity in one place.
- **Admin preview mode** — the local Curatorr administrator can now switch into a real Plex user context on the music pages to see the same scoped data that user sees.
- **Simpler overview stats** — dashboard and admin user metrics now show `7d / 30d / all time` directly instead of relying on a top-level period selector.
- **Playlist naming control** — generated playlists can now keep or drop the `(username)` suffix globally, and existing Plex playlists are renamed automatically when the setting changes.
