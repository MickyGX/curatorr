# Curatorr v0.1.51

## Summary

- **Docker image restored to Alpine** — reverts the runtime base from Debian slim back to `node:20-alpine`, which is smaller and what existing deployments were built around.
- **CI no longer hangs** — test suite now exits cleanly instead of blocking for 25+ minutes on every push.

## Fixed

- Fixed Docker image bloat caused by the Debian slim base introduced in v0.1.48 — Alpine restores the smaller, faster image with `wget` explicitly included so compose healthchecks continue to work.
- Fixed `server.close()` in the test teardown hanging indefinitely due to HTTP keep-alive connections not being released — `closeAllConnections()` is now called first.
- Fixed the media server session polling timer in the webhook handler missing `.unref()`, which kept the Node.js process alive after tests completed and caused every CI run to hang until the GitHub Actions timeout.

## Upgrade Notes

- No app configuration changes are required.
- Pull `mickygx/curatorr:latest` and recreate the `curatorr` container as usual.
