# Curatorr v0.1.32

## Summary

- **Blend header controls restored** — the Blend page once again exposes the injected version badge and theme toggle in the top bar, matching the rest of the dashboard pages.
- **Blend layout polish** — the blend summary and results panels now use tighter, more even spacing, smaller helper copy, and better-balanced Top Blended Artists / Top Blended Tracks panel sizing.
- **Carousel edge gutter fix** — the Playlists and Blend carousels now restore the left-side inset before the first visible card instead of rendering flush against the panel edge.

## Upgrade Notes

- No database migration required. Drop-in replacement for v0.1.31.
- Rebuild and redeploy the container so the updated Blend shell and carousel spacing are included in the running image.
- If Blend or Playlists still shows stale spacing or missing header controls after upgrade, do one hard refresh.
