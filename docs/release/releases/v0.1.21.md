# Curatorr v0.1.21

## Summary

- **Consistent playlist naming** — all Curatorr-managed playlists in Plex now follow the `Type (Username)` format so the playlist purpose is visible in Plexamp's truncated list. Global playlists previously named `Username - Playlist Name` and personal playlists previously named just `Playlist Name` are now renamed to `Playlist Name (Username)` on first sync after upgrade.
- **Automatic Plex playlist rename on sync** — whenever a playlist's desired title differs from what Plex currently holds (including after the format change above or after a legacy-name migration), Curatorr now issues a `PUT` rename to Plex during sync so titles stay consistent without manual intervention.
- **Legacy Daily Mix rename** — the old `Username's Daily Mix` format is detected and renamed to `Daily Mix (Username)` automatically on the first Daily Mix sync after upgrading.
- **Last.fm station playlist fixes** — fixed two bugs introduced in v0.1.18: the Plex machine ID was being resolved with the wrong argument (preventing station playlists from being created in Plex), and the master track lookup used snake_case column names while `getMasterTracks` returns camelCase (causing 0 matches). Station playlists now populate correctly.

## Upgrade Notes

- **No database migration required** — all changes are in playlist sync logic only.
- On the first Smart Playlist Sync after upgrading, all Crescive, Curative, global, and personal playlists will be renamed in Plex to the new format. This is a one-time in-place rename — no duplicate playlists will be created.
- If you have Last.fm station playlists enabled, they will now correctly populate with matched tracks from your Plex library.
