# Curatorr Release Announcement

Curatorr `0.1.29` is out.

## Highlights

- **New Blend page** — compare listening overlap from a dedicated blend view with ranked compatibility cards, artwork-backed user tiles, and shared top artists and tracks.
- **Blended smart playlists** — build smart playlists from two or more users so shared sessions can pull from combined taste rather than one person’s history alone.
- **Plex token fetch in setup wizard** — the server wizard can now redirect through Plex owner sign-in, save the server token automatically, and continue setup cleanly.
- **Empty Plex genre picker fixed** — the user wizard now bootstraps Plex data correctly when the token was skipped earlier, so favourite genres and artists populate instead of showing an empty step.
- **Playback and Lidarr reliability** — repeated Plex track plays are tracked correctly, and Lidarr artist-list requests are more resilient on large libraries.
