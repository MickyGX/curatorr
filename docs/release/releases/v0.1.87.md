# Curatorr v0.1.87

## Summary

- **New Music Mix starting point.** Smart playlist creation now includes a New Music Mix template for recent library additions. It defaults to tracks added in the last 90 days, caps selection at one track per album, limits the playlist to 50 tracks, and sorts by newest additions.
- **Release-aware smart playlist filtering.** Smart playlists can now filter by release year ranges, explicit release date ranges, and rolling release windows. This makes it possible to separate "recently added to the library" from "recently released" for Release Radar or New Music Friday-style playlists.
- **Added-to-library metadata support.** The master track cache now stores `library_added_at` and populates it from Plex `addedAt` plus Jellyfin/Emby `DateCreated` metadata during Master Track Cache Refresh.
- **New playlist sort modes.** Smart playlist previews and rebuilds now support sorting by newest library additions and newest releases, alongside the existing rating, tier, play count, random, and audio-feature sort modes.

## Fixed

- Added `library_added_at` to `master_tracks` with an automatic migration for existing databases.
- Updated Plex master-track import to store each track's library added timestamp from Plex metadata.
- Updated Jellyfin and Emby master-track import to request and store each track's `DateCreated` timestamp.
- Added smart playlist rules for:
  - added within / not added within the last N days
  - release year from / to
  - release date from / to
  - released within / not released within the last N days
- Added the new rules to both preview generation and actual smart playlist rebuild/sync logic.
- Added "Newest library additions" and "Newest releases" sort options to the playlist wizard and API allowlist.
- Added a New Music Mix built-in template to the smart playlist wizard starting points.
- Added wizard summary and payload handling for the new date-based rules.
- Added tests covering media-server library-added timestamp import, persistence, release-year filtering, release-window filtering, and album variety behavior.

## Upgrade Notes

- Database migration is automatic. On first start, Curatorr adds `master_tracks.library_added_at` if it is missing.
- Existing installs should run **Settings > Jobs > Master Track Cache Refresh** after upgrading so `library_added_at` is populated from Plex, Jellyfin, or Emby metadata.
- Release-year and release-date filters use stored media-server and enrichment metadata. For best release-date coverage, run the existing **Track Enrichment Sync** job after upgrading.
- No environment variable changes required.
- No media-server reconnection required.
