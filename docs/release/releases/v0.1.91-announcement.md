# Curatorr Release Announcement

Curatorr `0.1.91` is out.

## Highlights

- **Folder browser lists your whole library** - the smart playlist Step 4 folder browser (and the Settings global-playlist browser) no longer stop partway through the alphabet on large one-folder-per-artist libraries.
- **Lidarr retry job no longer gets stuck** - "Retry Failed Requests" used to wedge permanently once duplicate failed rows piled up for the same artist/album; it now dedupes and re-queues safely, and clears an already-stuck queue automatically.
- **No duplicate failed requests** - re-requesting an album now revives its existing failed row instead of stacking another.
