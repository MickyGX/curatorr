# Curatorr Release Announcement

Curatorr `0.1.66` is out.

## Highlights

- **Discover now verifies and repairs Lidarr monitoring** so unmonitored catalog albums stay requestable and completed requests can recover when Lidarr is not actually monitoring the album.
- **Force Search is now available from queue rows and monitored album cards** without reloading the Discover page.
- **Smart-playlist dedupe can now be inspected** with new duration/variant/live-album guards plus CSV copy/download for skipped duplicate matches.
