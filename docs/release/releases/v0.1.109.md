# Curatorr v0.1.109

## Summary

This release adds combined playlists, a password sign-in for Plex accounts, and a reorganised Jobs page with Run all. It also adds experimental import of TIDAL mixes.

## Added

- **Combined playlists**: choose **Combined** as the starting point in the playlist wizard, then pick two or more of your existing playlists, for example your newest tracks and your most played. ([#153](https://github.com/MickyGX/curatorr/issues/153))
- Combined playlists can use any of your synced Curatorr playlists: smart, system, imported or global.
- A combined playlist pools its sources' tracks, removes duplicates, then sorts and caps them with the usual output rules, like any playlist.
- A combined playlist rebuilds from its sources' current tracks on its schedule, after your other playlists. It can't use another combined playlist as a source.
- **Password sign-in for Plex accounts**: sign in with Plex, open **User Profile → Password sign-in**, and set a password. You can then sign in with your Plex username or email and that password when Plex sign-in is blocked, for example on a work VPN.
- Password sign-in opens the same account as a Plex sign-in, with the same playlists, history and role. Role and disabled status are checked on every sign-in.
- Only a Plex sign-in can set or change the password, so someone who only knows the password can't lock you out.
- Admins can see which Plex accounts have password sign-in in **Settings → Users** and remove it there.
- **Run all jobs** and **Run group** in **Settings → Jobs** run jobs one at a time, in the order they usually need to run, with progress shown. The Track Analysis Pipeline runs last because it can take a long time.
- **TIDAL mix import (experimental)**: paste a `tidal.com/mix/...` link into the URL tab of the import dialog. Not every mix may be available to Curatorr; if TIDAL refuses one, the preview says so. ([#180](https://github.com/MickyGX/curatorr/issues/180))

## Changed

- **Settings → Jobs** is grouped into Library, Listening history, Track metadata and analysis, Discovery and Lidarr, and Playlists, with a job and failure count on each group.
- Each job is a compact row with its status, last result, interval, Enabled and Run now. The description is under **About this job**, and failed jobs sort to the top of their group.
- Jobs for integrations that are not set up are marked **Not configured** and skipped by Run all and Run group.
- **Playlist Account Maintenance** now sits in the Playlists group.
- The Rotating Playlist Sync job is now called Daily Mix and Curatorr Playlist Sync.

## Fixed

- Job result messages are inserted as plain text when the Jobs page refreshes, so playlist or file names in a message can't be read as HTML.
- Added regression tests for combined playlists, password sign-in, job groups and run sequences, and TIDAL mix links.

## Upgrade Notes

- Update the Curatorr app image and recreate the container as usual. No analyzer update is required.
- No database changes. Password sign-ins are stored in the config file, as scrypt hashes.
- Password sign-in uses the Plex server token saved at the user's last Plex sign-in. If Plex revokes it, signing in with Plex once refreshes it.
- Details: `docs/wiki/Smart-Playlists.md#combined-playlists`, `docs/wiki/Authentication-and-Roles.md` and `docs/wiki/Configuration.md#jobs`.
