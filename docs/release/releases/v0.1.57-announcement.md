# Curatorr Release Announcement

Curatorr `0.1.57` is out.

Highlights:

- **Admin users table play stats fixed** — users showing "No play history yet" and 0 plays (despite having real history) are now correctly matched to their database records. The table now uses the exact identifier Tautulli stored, not a username derived from the Plex API.
- **Lidarr track count now tracked** — albums added via Lidarr now record their track count, populating the previously always-blank tracks column in the admin users table going forward.
- **Retry failed Discover adds** — failed "Added for you" items now have an inline retry icon that re-queues the request and immediately re-attempts processing.
