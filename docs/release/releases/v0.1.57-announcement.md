# Curatorr Release Announcement

Curatorr `0.1.57` is out.

Highlights:

- **Startup time fixed** — the app was taking 30+ seconds to start on NAS hardware because every log entry triggered a synchronous 239 KB disk write. Startup is now near-instant.
- **General sluggishness fixed** — the same synchronous write was happening on every log-generating request during normal use. Page loads that triggered log entries will feel dramatically faster.
