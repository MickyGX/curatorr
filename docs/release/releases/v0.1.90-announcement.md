# Curatorr Release Announcement

Curatorr `0.1.90` is out.

## Highlights

- **Scheduled rebuilds for Plex owner/admin installs** - Smart Playlist Sync and Rotating Playlist Sync now handle cases where the real Plex owner shares an id with the local setup-admin account.
- **No-op job success fixed** - affected schedulers should now select the real playlist owner instead of completing in milliseconds without rebuilding due playlists.
- **Setup account guard preserved** - true setup-only local accounts remain excluded from personal playlist scheduler work.
