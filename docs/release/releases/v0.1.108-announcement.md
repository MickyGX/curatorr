# Curatorr v0.1.108 Announcement

Curatorr `v0.1.108` makes the main pages much faster on large libraries.

## Highlights

- **Faster pages**: on a library of about 385,000 tracks, Discover now loads in under 0.1 seconds instead of about 6, and Overview in about 1 second instead of about 6.
- **No more stalls**: other requests no longer wait behind a slow page load.
- **Community contribution**: thanks to @quinneydavid ([#183](https://github.com/MickyGX/curatorr/pull/183)).
