# Curatorr Release Announcement

Curatorr `0.1.64` is out.

## Highlights

- **Discover and Lidarr now reconcile at the album level** with support for close edition matches like standard vs deluxe, which fixes more stuck request and repeated-search cases.
- **Discover request handling is cleaner** with a true Queue vs Added For You split, plus row action menus for retry, delete, and manual mark-available overrides.
- **Discover popups and menus behave better** with restored modal scrolling, smarter in-panel menu positioning, and drag handles hidden where reordering is not actually available.
