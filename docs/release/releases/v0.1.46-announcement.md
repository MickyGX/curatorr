# Curatorr Release Announcement

Curatorr `0.1.46` is out.

Highlights:

- **One smart-playlist wizard for everything** — personal, blend, and global playlists now share the same create/edit flow, and existing playlists reopen in the wizard with their settings prefilled.
- **New settings-based starters** — the wizard now includes `Curatorr`, `Crescive`, and `Curative` starting points, plus a new `Wake Up` audio profile.
- **Clearer previewing and stronger filter controls** — eligible-pool vs final-playlist counts, tri-state tiers, and cleaner advanced filtering make playlist shaping much easier.
- **Analyzer runs are more robust** — unreadable tracks are skipped instead of crashing the whole analysis chunk.
