# Curatorr v0.1.82

## Summary

- **The setup/local admin account is now treated as a recovery account, not a listener profile.** It can no longer run the personal music wizard, build personal playlists, or participate in Lidarr automation paths that should belong only to real media-server users.
- **Existing installs now clean up stale setup-admin music data automatically on startup.** Curatorr removes old personal stats, discovery rows, preferences, and related user-scoped records that were previously attached to the fallback admin identity.
- **Background jobs and personal page scope now ignore the setup admin consistently.** Scheduler loops, recommendation rebuilds, and personal data views skip the setup admin unless an administrator is explicitly previewing another user.

## Fixed

- Blocked the local setup admin from entering `/wizard/user` and all user-wizard submission paths, redirecting the recovery account back to Overview instead of allowing it to create personal music state.
- Blocked the setup admin from manual playlist rebuild actions that would otherwise recreate personal playlist state for the fallback admin.
- Disabled Lidarr automation access for the local setup admin even when admin role quotas and global automation are enabled.
- Disabled setup-admin identities inside background Lidarr role resolution so scheduler-driven artist automation no longer treats the fallback admin as an eligible requester.
- Filtered the setup admin out of scheduled smart-playlist sync, Daily Mix sync, suggestion rebuild, failed-request retry, and blended global-playlist user loops.
- Cleared personal-page scoping for the setup admin when not previewing another user, preventing Overview and related personal surfaces from defaulting to stale recovery-account data.
- Added a startup cleanup pass that purges stale setup-admin rows from user-scoped music tables, including listening stats, user preferences, suggestion tables, Lidarr request state, and playlist-rule templates.
- Added cleanup for stale setup-admin Plex token aliases and Plex login aliases in config when those identities were previously persisted there.
- Added focused regression coverage for setup-admin wizard redirects, Lidarr automation blocking, background-role disabling, and the scoped database cleanup behavior.

## Upgrade Notes

- No manual migration is required for this release. On first startup after upgrading, Curatorr automatically removes stale setup-admin music data if it finds any.
- The setup/local admin should now be treated as a recovery/configuration account only. Use a real media-server user identity for personal discovery, playlists, and automation flows.
- If you previously saw personal stats or recommendation data attached to the fallback admin, that data will be removed during startup cleanup and will not be recreated for the setup admin going forward.
