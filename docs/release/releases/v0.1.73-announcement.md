# Curatorr Release Announcement

Curatorr `0.1.73` is out.

## Highlights

- **Suggested artists now reconcile against Lidarr before review runs**, so artists you already added manually in Lidarr stop reappearing as new Curatorr suggestions.
- **Acquired artist progress is more stable** when Lidarr album ids change, with Curatorr preserving `album_acquired` status if Lidarr still reports downloaded files.
- **Discovery suggestions are cleaner** because collaboration credits like `feat.`, `ft.`, and known joint artist credits are filtered out.
