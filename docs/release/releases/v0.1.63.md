# Curatorr v0.1.63

## Summary

- **Imported playlists can now become editable smart playlists** — imported Plex playlists, Plex collections, and Spotify playlists can now be converted into personal smart playlists with inferred audio settings, inferred genre/mood/tag chips, and controls to switch between recommended chips and every detected content value from the matched source tracks.
- **Zero-result smart playlists no longer dead-end the workflow** — Curatorr now validates smart-playlist saves before syncing, allows personal playlists with zero current matches to be saved as drafts, and surfaces those drafts on the Playlists page so they can be edited instead of disappearing into an unusable state.
- **Playlist, Blend, and dashboard layouts were tightened together** — the smart-playlist wizard copy and controls were clarified, Step 2 chip handling is more explicit, and the dashboard/blend stat rows and panel spacing were rebalanced to feel closer to one shared UI system.

## Fixed

- Added imported-playlist conversion from the Playlists page into the smart-playlist wizard, including inferred audio preset, BPM/energy/danceability ranges, inferred genres/moods/tags, and preserved source metadata for later edits.
- Added imported content-state controls in Step 2 of the smart-playlist wizard so audio-profile suggestions can be applied or removed explicitly, imported conversions can toggle between recommended chips and all detected chips, and all Step 2 content filters can be cleared in one action.
- Fixed the confusing “audio-ready but 0 final tracks” workflow by validating personal and global smart playlists before saving, returning a clear `0 tracks` error for non-draft saves, and exposing `Save as Draft` when a personal playlist currently matches nothing.
- Added personal draft surfacing on the Playlists page so saved zero-track personal playlists appear as Curatorr drafts with appropriate empty-state and delete behavior instead of vanishing until a generated playlist exists.
- Fixed rebuild handling for personal/global playlist keys so smart-playlist operations can resolve playlist type correctly even when a generated row does not already exist.
- Added support for removing the original imported mirror after converting it into a smart playlist, while still allowing users to keep the original import when preferred.
- Tightened Blend page spacing, card density, stat-card sizing, and dashboard stat-grid spacing so the Blend and dashboard layouts align more closely with the rest of the app.
- Added regression coverage for zero-track personal playlists, imported smart-playlist inference, detected-content persistence, and imported-source removal behavior.

## Upgrade Notes

- Recreate the app container after pulling `mickygx/curatorr:latest`.
- Hard refresh the browser after upgrading. This release changes large sections of the smart-playlist wizard and shared CSS, so cached assets can make the interface look stale.
- Existing zero-track personal playlist definitions should now appear as drafts on the Playlists page after upgrade, as long as the saved personal playlist record already exists in Curatorr.
- Global smart playlists can no longer be saved if the current rules match zero tracks; personal playlists can still be saved in that state, but only as drafts.
