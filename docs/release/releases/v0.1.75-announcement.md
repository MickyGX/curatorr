# Curatorr Release Announcement

Curatorr `0.1.75` is out.

## Highlights

- **Artist collaboration filtering is broader and simpler**, so guest-collaboration credits are suppressed as soon as any credited artist already exists in your library.
- **Comma-separated guest credits are handled more reliably**, improving recommendation cleanup for joint artist names with multiple guests.
- **Band-name guardrails remain in place**, so the tighter collaboration filter is less likely to catch obvious named-band components by mistake.
