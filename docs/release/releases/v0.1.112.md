# Curatorr v0.1.112

## Summary

This is a security release. It closes a hole in the setup wizard and hardens several other areas. It also fixes Jellyfin and Emby webhooks, makes playlist dialogs work with the keyboard, and replaces browser pop-ups with themed dialogs. Upgrade promptly if Curatorr is reachable from outside your home network, for example through a reverse proxy.

## Security

- **Setup wizard stayed open after setup.** The setup wizard's steps did not check whether setup was finished or who was signed in. Anyone who could reach Curatorr could create an admin account. They could also make Curatorr send the saved Plex token to a server of their choosing. The wizard steps are now closed once setup is complete. Before that, only the first step (creating the admin account) is open, and only until an account exists. Every later step needs the admin to be signed in. The Plex sign-in that fetches a server token for the wizard follows the same rule. The personal setup that new users go through is unchanged.
- **Artwork images needed no login.** The track, artist and album artwork and album cover images, and the Discover artist images, are fetched through your Plex, Jellyfin or Lidarr credentials. Anyone could request them without signing in. They now need a login. Requests to the servers behind them also stop waiting after 8 seconds.
- **System log was visible to every user.** Any signed-in user could read the system log, which includes other users' names and actions. It is now limited to admins and co-admins, the same people who can open **Settings → Logs**.
- **Page data was not escaped.** Some pages embed library data, such as artist names, genres and Last.fm tags, in their scripts. A name containing `</script>` could break out of the script. All such data is now escaped.
- **Damaged `config.json` replaced with defaults.** If `config.json` could not be read, for example after a bad manual edit, Curatorr quietly switched to default settings. The next time it saved, it overwrote the real file with them. It now logs the error and keeps running on the last settings that loaded. Before saving, it copies the damaged file to `config.json.unreadable-<time>`.
- **`config.json` permissions.** `config.json` holds server tokens, API keys and password hashes. It is now readable by its owner only (`600`), both when Curatorr saves it and when the container starts. It was `644` before.

## Fixed

- **Jellyfin and Emby webhooks rejected.** Webhooks from Jellyfin and Emby were rejected with a 403 "Invalid CSRF token" before their webhook key was checked. Curatorr fell back to polling for playback. They are now accepted like the Plex and Tautulli webhooks, and still require the webhook key.
- **Unstyled buttons in Settings.** Some Settings buttons showed as plain browser buttons. These were the global playlist Edit, Delete and Add Rule buttons and the folder browser buttons.
- **Bulk playlist delete hid failures.** It reloaded the page as if every playlist had been deleted. It now reports how many could not be deleted. Deleting a global playlist in Settings also shows an error instead of failing silently.
- **Settings did not reopen the last tab.** It always opened on General. It now reopens the last tab you used when you open Settings without choosing one.

## Improved

- **Playlist dialogs:**
  - Escape closes the open dialog.
  - Tab and Shift+Tab stay inside it.
  - Opening a dialog moves focus to its first field. Closing it returns focus to where you were.
- **Unsaved changes in the smart playlist builder.** Closing it with the close button, Cancel, a click outside or Escape now asks before discarding unsaved changes. Saving still closes it straight away.
- **Themed dialogs and notifications.** Browser pop-ups are replaced on the Playlists, Discover, Settings and User Profile pages.
  - Errors appear as notifications in the corner.
  - Confirmations use a dialog that matches your theme. Delete confirmations start on Cancel, so pressing Enter does not delete by mistake.
  - After a delete, a notification confirms it.
- **Settings tabs:**
  - Logs and About are now at the end of the tab bar.
  - Arrow keys, Home and End move between tabs, and screen readers announce them as tabs.
  - Clicking a tab adds it to the address, for example `/settings#lidarr`, so you can link to it.
- **Keyboard focus.** Filter buttons, panel collapse buttons, toggle switches and a few other controls show a focus ring again.
- **"Plex" wording.** The global playlist delete prompt now names Jellyfin or Emby instead of always saying Plex.
- Added regression tests for:
  - the setup wizard rules
  - Jellyfin and Emby webhooks
  - artwork image and system log access
  - page data escaping
  - recovery from a damaged `config.json`

## Upgrade Notes

- Update the Curatorr app image and recreate the container as usual. The analyzer image is unchanged.
- No database changes.
- Artwork image URLs now need a login. If you show Curatorr artwork outside Curatorr, such as in a dashboard widget, it will no longer load there.
- `config.json` is now `600`, owned by the user Curatorr runs as. If a backup tool reads it as a different user, give that tool access another way.
- If you use Jellyfin or Emby webhooks, they start working with this release. No changes are needed on your server.
