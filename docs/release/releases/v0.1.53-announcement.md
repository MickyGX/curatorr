# Curatorr Release Announcement

Curatorr `0.1.53` is out.

Highlights:

- **Windows desktop startup crash fixed** — upgrading from an older install no longer causes a fatal crash on launch. The database migration now correctly handles partial indexes on columns added in recent versions.
- **Dashboard stat counts fixed** — excluded tracks, skip-tier artists, belter tracks, and heard tracks now show the correct numbers for the logged-in user.
