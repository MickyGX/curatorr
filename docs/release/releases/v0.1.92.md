# Curatorr v0.1.92

## Summary

- **Folder selection is searchable.** Smart Playlist Include/Exclude folder pickers now have live search in both the wizard and Settings global-playlist builder, searching the full folder tree instead of only the current branch.
- **Plex artist countries are playlist filters.** Curatorr now stores Plex artist country metadata and exposes it as a Smart Playlist tri-state filter, so country-based playlists can be built without maintaining large folder lists.
- **Studio copies can win over common variants.** A new cleanup option prefers regular studio recordings over live, demo, acoustic, remix, and instrumental variants when a studio copy exists.

## Fixed

- The Smart Playlist wizard and Settings global-playlist folder pickers now support live search across all known folders. Prefix matches rank first, results include parent paths where useful, and large result sets are capped with a hint to keep typing.
- Plex master-track refresh now hydrates artist-level `Country` metadata onto tracks, stores it in `master_tracks.artist_countries`, and exposes distinct country values to playlist pages.
- Smart Playlist preview and final generation now both apply `artistCountries` include/exclude rules.
- Imported playlist smart-conversion now carries detected and suggested artist-country values when matched source tracks have country metadata.
- Added a dedicated `preferStudioRecordings` track filter that drops likely non-studio variants only when a regular studio recording survives earlier filters. Variants remain when no studio version exists.
- Global playlist updates now preserve the artist-folder cleanup preference and persist the new studio-preference cleanup flag.

## Upgrade Notes

- A database migration adds `master_tracks.artist_countries` automatically on startup.
- Run **Jobs -> Master Track Cache Refresh** after upgrading to populate Plex artist country values for existing libraries.
- Jellyfin and Emby installs continue to work normally; artist-country chips simply remain unavailable until a media server provides that metadata.
- Existing smart playlists keep their current behavior until the new artist-country or studio-preference options are selected.
