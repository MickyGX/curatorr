# Curatorr Release Announcement

Curatorr `0.1.92` is out.

## Highlights

- **Searchable folder pickers** - Include/Exclude folder selectors now search the full folder tree in both the smart playlist wizard and Settings global-playlist builder.
- **Plex artist country filters** - build playlists around countries like Netherlands, United Kingdom, France, or Canada after refreshing the master track cache.
- **Prefer studio recordings** - optionally drop live/demo/acoustic/remix-style variants when a regular studio copy exists.
