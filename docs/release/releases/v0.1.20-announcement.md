# Curatorr v0.1.20 Announcement

Curatorr `v0.1.20` is out.

## Highlights

- **Last.fm Station Playlists now actually work** — two bugs in v0.1.18/v0.1.19 meant Recommended, Mix, and Library playlists were being created in Plex but always empty, and all three were sharing the same Plex playlist ID (overwriting each other). Both are fixed: tracks match correctly and each station gets its own independent playlist.
- If you enabled stations in User Profile, upgrade and run a Smart Playlist Sync — you should see three separate playlists appear in Plex with tracks from your library.
