# Curatorr v0.1.103 Announcement

Curatorr `v0.1.103` adds TIDAL playlist import and fixes local password changes.

## Highlights

- **TIDAL playlist import**: connect TIDAL in User Profile, then browse, preview, and import your playlists from the new TIDAL tab, with scheduled refresh.
- **TIDAL links in the URL tab**: import public TIDAL playlists without connecting an account.
- **Local account fix**: changing a local password and adding local users work again.
