# Curatorr v0.1.10

## Summary

- Added personal smart playlists, including a creation modal, preview counts, rebuild support, and Plex sync for user-defined playlist rules.
- Expanded smart playlist filtering with library genres, Plex moods, and stored Last.fm artist tags across both admin-defined global playlists and user-created personal playlists.
- Improved playback history accuracy by consolidating split listens within a 10-event lookback, so pause/resume and quick restart flows accumulate into one play event instead of generating false skips.
- Added a scheduled Last.fm tag sync job and mood ingestion during master track refresh, giving playlist rules richer metadata to target.

## Upgrade Notes

- Rebuild and redeploy Curatorr so the updated webhook handling, playlist APIs, settings UI, and new sync job are included in the running image.
- Existing split play-history rows are not auto-migrated on upgrade. If you want to collapse older false split entries, run `docker exec curatorr node /app/src/scripts/consolidate-play-events.js <userPlexId>` after deploying.
- Do a hard refresh after upgrade so the updated playlist, settings, and history assets replace older cached files.
