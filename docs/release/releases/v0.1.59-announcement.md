# Curatorr Release Announcement

Curatorr `0.1.59` is out.

Highlights:

- **Much faster first load on NAS installs** — startup no longer blocks on the heaviest playlist/master-track work before the server is reachable, and SQLite cold-start handling was tuned to avoid the long initial lag.
- **Saved smart-playlist templates now work as true starting points** — templates keep advanced filters and their original starter, can be selected at the start of the wizard, and can now be updated or deleted.
- **Lower startup overhead in Docker** — Curatorr avoids full recursive ownership rewrites on boot, reducing needless disk churn on larger libraries and slower storage.
