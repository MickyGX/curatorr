# Curatorr Release Announcement

Curatorr `0.1.88` is out.

## Highlights

- **Scheduled rebuilds that actually run** - daily and weekly jobs (Daily Mix, Curatorr rotating playlists, Tautulli gap-fill, Last.fm tags) no longer get starved on setups that restart often; overdue jobs now catch up automatically after startup.
- **Snappy during rebuilds** - a Smart Playlist Sync over a big library no longer locks up the UI or trips container healthchecks.
- **Prefer artist-folder copies over compilations** - a new smart playlist filter that drops the "Various Artists" copy of a track when you already have it in an artist folder.
- **Playlist created date** - the detail panel now shows when a playlist was created, next to its last-updated date.
