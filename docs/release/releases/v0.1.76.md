# Curatorr v0.1.76

## Summary

- **Discover rebuilds now clean up stale collaboration suggestions** so old joint-credit artist rows that survived from earlier recommendation runs are removed automatically.
- **The collaboration filter now applies to retained suggestion rows as well as new suggestions**, which means upgrading no longer leaves older noisy collaboration credits hanging around in the pipeline.
- **Users get cleaner artist recommendations immediately after a rebuild** without waiting for suggestion retention windows to expire.

## Fixed

- Added a cleanup pass during recommendation rebuilds that scans retained `suggested` artist rows for collaboration credits and deletes stale matches.
- Fixed old joint-credit suggestions persisting in Discover when they were generated before the collaboration filter existed.
- Applied the existing collaboration-credit heuristic to previously stored recommendation rows, not just newly generated candidates.
- Reduced stale recommendation noise for collaboration names that would now be filtered under the current artist suggestion rules.
- Kept the cleanup limited to `suggested` rows so actioned or dismissed artist states are not touched by the purge.
- Ensured collaboration cleanup runs as part of the normal rebuild flow, with no manual database cleanup required.

## Upgrade Notes

- No manual migration is required for this release.
- Stale collaboration suggestions will be removed the next time Curatorr rebuilds artist recommendations for a user.
- If you still have old joint-credit suggestions visible after upgrading, trigger or wait for the next recommendation rebuild cycle.
