# Curatorr v0.1.10 Announcement

Curatorr `v0.1.10` is out.

## Highlights

- You can now create personal smart playlists with your own rule set and sync them directly to Plex.
- Global and personal playlist filters now understand genres, Plex moods, and stored Last.fm artist tags.
- Playback tracking now consolidates split listens within a 10-event window, reducing false skip rows caused by pause/resume or quick restart flows.
