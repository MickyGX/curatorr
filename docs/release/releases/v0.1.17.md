# Curatorr v0.1.17

## Summary

- **Dashboard period toggle** — the Overview Stats panel now has a `7d · 30d · All` filter toggle in the panel title bar (Launcharr-style filter buttons). The six stat cards (Plays, Skips, Skip Rate, Listen Time, Artists, Tracks) show the selected period's value with a comparison sub-line for the adjacent period. Switching periods updates all cards client-side with no page reload.
- **Stat card icons** — all stat cards in Overview Stats and the "Curatorr at a glance" panel now display a large theme-coloured icon on the right of the card with a subtle brand-colour glow.
- **Library Artists glance card** — the "Playlist last synced" glance card is replaced with a Library Artists count: unique artists across the entire master track cache, including artists on Various Artists compilations but deduplicated and excluding placeholders (`Various Artists`, `VA`, `V/A`, `Unknown`).
- **Playlist delta tracking** — playlist cards on both the dashboard and the Playlists page now show a track delta badge overlaid on the artwork. A green pill shows tracks added, red shows tracks removed, and amber `=` indicates no change since last sync. The delta is persisted via two new columns (`tracks_added`, `tracks_removed`) added to the `playlist_syncs` table.
- **Last.fm dedup improvements** — duplicate detection for Last.fm scrobble backfill is significantly more robust: the lookback window is now asymmetric (using the known track duration rather than a fixed ±90 s window), Unicode non-breaking hyphens (U+2010 and variants) in artist names stored by Tautulli are normalised to ASCII on both sides of the comparison, and Tautulli's `"Track Title - Artist Name"` suffix format is matched with a SQL `LIKE` clause.

## Upgrade Notes

- **Database migration runs automatically** — two new columns (`tracks_added`, `tracks_removed`) are added to `playlist_syncs` via idempotent `ALTER TABLE` on startup. No manual action required.
- Delta badges will show `=` for any playlists synced before this version, as historical delta values default to `0`. They will begin reflecting real deltas from the first sync after upgrade.
- No changes to environment variables, config schema, or external integrations.
