# Curatorr Release Announcement

Curatorr `0.1.44` is out.

Highlights:

- **Analyzer sidecar tag builds fixed** — the analyzer worker scripts are now tracked in Git, so release-tag builds can copy them into `mickygx/curatorr-analyzer`.
- **Analyzer image publish repaired** — the sidecar image now builds from tagged GitHub Actions releases instead of failing on missing `scripts/...` files.
- **AMD64 and ARM64 support preserved** — the analyzer image continues to publish for both `linux/amd64` and `linux/arm64`.
