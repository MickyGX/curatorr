# Curatorr Release Announcement

Curatorr `0.1.30` is out.

## Highlights

- **Plex Home login-loop fix** — users who authenticate with Plex Home profiles should no longer get bounced back to the login page after successful sign-in.
- **Blend page shell fix** — the Blend page now matches the rest of Curatorr again, including the animated music-note background and the working user-pill menu.
