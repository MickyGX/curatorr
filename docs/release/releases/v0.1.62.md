# Curatorr v0.1.62

## Summary

- **Overview popups now feel like first-class media pages** — Curatorr’s artist, album, track, and manual-discovery popups now use a Launcharr-style layout with square posters, fixed artist backdrops, improved desktop/mobile sizing, and internal text scrolling instead of unstable full-modal scroll behavior.
- **Discover rows are now much more reliable and actionable** — artist and album cells on the Discover page now open the correct popup, manual/Lidarr album rows keep the right album artwork, and failed requests now show a proper retry control instead of a tiny broken inline icon.
- **Page spacing and table behavior are more consistent across the app** — dashboard, discover, history, sidebar, and playlists layouts were tightened so panel spacing, carousel gutters, and sticky headers behave more like one shared design system.

## Fixed

- Fixed Curatorr overview modals so album and track posters render at a square ratio where expected, the large background uses artist art instead of mismatched album art, and desktop/mobile modal sizing now behaves more like Launcharr.
- Fixed overview track lists so multi-disc albums use sequential display labels (`CD 1`, `CD 2`, etc.) even when upstream media numbering is sparse, and ISO release timestamps now display as plain dates.
- Fixed manual-discovery album and Curatorr-pick artwork resolution so stored Lidarr image paths and release-group cover fallbacks are used before falling back to generic artist thumbnails.
- Fixed Discover queue/history rows so both artist and album cells are selectable and open the relevant popup instead of acting like dead text.
- Fixed Discover failed-request actions by replacing the undersized retry icon with a proper styled retry button.
- Fixed History table scrolling so the top header row remains visible while you scroll to the bottom of the play list.
- Fixed the left sidebar dashboard separator regression by removing the extra divider line above the dashboard icon.
- Tightened dashboard, discover, and playlists spacing so panel gaps and carousel insets line up more closely with the rest of the app.
- Fixed playlists-page carousel behavior so the table scroll can collapse and re-expand the carousel correctly again, while keeping a small visual gap between the carousel and the track table.
- Added album artwork persistence to imported unmatched playlist rows in the database so imported playlist review can retain album images alongside unmatched track metadata.
- Moved the Buy Me a Coffee button in the README from the crowded badge row to the bottom community/support area.

## Upgrade Notes

- Recreate the app container after pulling `mickygx/curatorr:latest`.
- Hard refresh the browser after upgrading. This release changes shared modal JavaScript and large sections of the app stylesheet, so stale cached assets can make the UI look unchanged or broken.
- Existing imported unmatched playlist rows gain the new album-image field automatically through migration, but some older rows may still need an import refresh before richer stored artwork appears.
