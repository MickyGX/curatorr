# Curatorr v0.1.107 Announcement

Curatorr `v0.1.107` makes large playlist libraries easier to manage and fixes the Daily Mix and Tautulli.

## Highlights

- **Playlist list view and search**: switch to a sortable list with 25, 50 or 100 playlists per page, and set auto-refresh for many imported playlists at once.
- **Daily Mix fixed**: it now fills to its full size and changes every day.
- **Tautulli fixes**: webhook registration no longer points at localhost, gap-fill works with selected libraries, and a new backfill recovers missed plays.
