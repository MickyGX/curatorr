# Curatorr v0.1.77

## Summary

- **Artist collaboration filtering is broader again** so duet labels, credits joined with `and`, and more multi-word joint-artist names are filtered out before they appear as standalone discovery suggestions.
- **URL playlist imports work correctly again from the Playlists page** because import actions now target the actual import endpoints instead of the preview-only routes.
- **Recommendation noise is lower across more naming variants** including soundtrack-style pairings, duet credits, and mixed guest-collaboration formats.

## Fixed

- Expanded the collaboration-credit keyword check to catch `duet` labels as automatic joint credits.
- Updated collaboration parsing to split artist names on commas, ampersands, and the word `and`, improving detection for more real-world joint-credit formats.
- Broadened the heuristic so joint names already in the library and multi-word credited artist parts are treated more aggressively as collaboration credits.
- Reduced false standalone recommendations for collaboration names that previously slipped through because they did not use only `feat.` or `&` separators.
- Fixed the Playlists page URL import action so import mode posts to `/api/music/import/<provider>` instead of the preview endpoints.
- Restored direct URL imports for Spotify, YouTube, Last.fm, and ListenBrainz from the Playlists page while keeping preview mode pointed at the dedicated preview routes.

## Upgrade Notes

- No manual migration is required for this release.
- Collaboration filtering improvements will apply the next time Curatorr refreshes or rebuilds artist recommendations.
- If URL imports from the Playlists page were only previewing or failing to import before, retry them after upgrading.
