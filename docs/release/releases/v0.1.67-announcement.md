# Curatorr Release Announcement

Curatorr `0.1.67` is out.

## Highlights

- **Admin Users playlist totals are now accurate** across alias IDs, without double-counting synced personal playlists.
- **Admin Users Lidarr stats now show real Curatorr usage only** instead of placeholder progress rows for already-monitored content.
- **Future Lidarr album adds now capture track totals reliably** even when Lidarr omits `trackCount` on the first album response.
