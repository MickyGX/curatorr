# Curatorr v0.1.70

## Summary

- **Playlist import is much broader and more maintainable** with YouTube playlist URL support, a dedicated URL import flow, and Last.fm plus ListenBrainz playlist imports moved into the main Playlists experience instead of being hidden behind profile toggles.
- **Imported playlists behave more like real Curatorr playlists now** because imported sources can auto-refresh on a daily, weekly, or monthly schedule, and that refresh control applies across Spotify, YouTube, Plex, Last.fm, and ListenBrainz imports.
- **Discover and overview workflows are clearer and less fragile** with the top discovery table reframed as an artist pipeline, queue drag affordances removed when they were not actually working, stale status labeling improved, and overview popups fixed for dashboard activity rows and non-library artists.

## Fixed

- Added public YouTube playlist URL preview and import support using `YOUTUBE_API_KEY`.
- Added a dedicated `URL` import tab that auto-detects supported playlist URLs and keeps URL-based imports separate from owned Spotify playlist browsing.
- Expanded imported playlist source support to include YouTube, Last.fm stations, and ListenBrainz generated playlists alongside Spotify and Plex imports.
- Added persisted imported-playlist auto-refresh periods with `Disabled`, `Daily`, `Weekly`, and `Monthly` options, plus scheduled refresh handling for imported playlists.
- Moved Last.fm and ListenBrainz playlist import flows out of User Profile toggles and into the Playlists import modal, while keeping only account-level settings in the profile page.
- Fixed imported playlist persistence so refresh settings survive rebuilds and imports can continue behaving like managed Curatorr playlists.
- Fixed history tier badges so stale skip flags no longer override the actual listened duration when deciding whether a play was a skip, half-decent listen, decent listen, or belter.
- Fixed overview popup rendering so items that only provide plain `overview` text still render correctly even without structured detail sections.
- Fixed dashboard and discovery artist activity popups for admin sessions and non-library artists by preserving the correct user context and providing better fallback overview text.
- Hardened overview fetch handling so non-JSON error responses no longer explode into raw JSON parse failures in the modal.
- Reworked Discover so the top table reads as an artist-level pipeline while the request queue is positioned as unresolved Lidarr handoff work, with clearer table descriptions to match.
- Cleaned up Discover queue UX by removing the non-working drag handle and dead reordering behavior.
- Updated dashboard discovery activity labels and supporting views so artist progression states like starter-album acquired vs awaiting belter read more consistently across the app.
- Added setup documentation for YouTube integration and refreshed the docs for Spotify, imported playlists, and the simplified Last.fm/ListenBrainz profile configuration.

## Upgrade Notes

- Recreate the Curatorr container after pulling this release:
  `mickygx/curatorr:v0.1.70`
- Hard refresh the browser after upgrading. This release updates shared frontend assets for Playlists, Discover, Dashboard, and overview popups.
- If you want YouTube playlist URL import, add `YOUTUBE_API_KEY` to the Curatorr container before testing the URL import tab.
- Existing imported playlists will pick up the new auto-refresh field automatically. Review the Playlists page if you want to enable periodic refresh on older imported playlists.
