# Curatorr v0.1.26 Announcement

Curatorr `v0.1.26` is out.

## Highlights

- **Plex Home login fix** — users on Plex Home setups no longer get kicked back to the login screen after selecting a profile in the embedded Launcharr popup.
- **Large library support** — the Master Track Cache Refresh no longer crashes with a memory error on libraries with 600k+ tracks; Plex data is now fetched in pages.
- **Plex token optional in wizard** — the setup wizard no longer requires a Plex token upfront; it's filled in automatically on first Plex owner login.
- **Last.fm Loved & Top Tracks playlists** — two new station playlist types in User Settings: sync your Last.fm loved tracks or your top tracks for a selectable time period (requires Last.fm API key in Discovery settings).
- **Station cleanup on disable** — disabling a Last.fm station now removes the playlist from Plex and Curatorr on the next sync.
