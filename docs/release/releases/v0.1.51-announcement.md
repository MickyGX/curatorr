# Curatorr Release Announcement

Curatorr `0.1.51` is out.

Highlights:

- **Docker image back to Alpine** — reverts from Debian slim to `node:20-alpine` for a smaller image; `wget` is included so compose healthchecks keep working out of the box.
- **CI fixed** — the test suite now exits cleanly on every push instead of hanging for 25+ minutes and needing manual cancellation.
