# Curatorr v0.1.107

## Summary

This release makes large playlist libraries easier to manage, with a list view, search, and bulk auto-refresh for imported playlists. It also fixes the Daily Mix, two Tautulli problems, and updates the bundled Node.js for a security fix.

## Added

- **Playlist list view**: the Playlists page has a **Cards / List** toggle and a search box. The list shows name, type, tracks, missing and last updated, sorts by any of name, tracks, missing or updated, and shows 25, 50 or 100 playlists per page. Its checkboxes work with the existing selection bar. Your view, sort and page size are remembered in your browser. ([#181](https://github.com/MickyGX/curatorr/issues/181), [#172](https://github.com/MickyGX/curatorr/issues/172))
- **Default auto-refresh for new imports**: admins set it in **Settings → Playlists → Imported Playlists**. The watch folder has its own **Auto-refresh for new watch-folder playlists** setting, which falls back to this default. ([#182](https://github.com/MickyGX/curatorr/issues/182))
- **Bulk auto-refresh**: select imported playlists on the Playlists page and choose a period from **Auto-refresh…** in the selection bar. ([#182](https://github.com/MickyGX/curatorr/issues/182))
- **Refresh all imported**: the **↻** button in the Playlists header queues every imported playlist and refreshes them in the background, 25 at a time. ([#182](https://github.com/MickyGX/curatorr/issues/182))
- **Tautulli history backfill**: the Tautulli card in Settings has **Backfill history** (1 to 365 days, default 60) to recover plays missed over a longer period than the daily gap-fill covers. ([#188](https://github.com/MickyGX/curatorr/issues/188))

## Fixed

- **Daily Mix**: each source was cut to a small fixed number of tracks before the one-track-per-artist rule ran, and nothing was random. New libraries got only a few tracks, and established ones got nearly the same mix every day. The mix now fills to its full size, rotates daily, avoids the previous day's tracks when there are enough alternatives, and stays the same if rebuilt later the same day. ([#184](https://github.com/MickyGX/curatorr/issues/184))
- **Tautulli webhook registration**: **Register webhook in Tautulli** registered `http://localhost:7676` when no Curatorr URL was saved, even though Settings showed the correct URL. It now uses the same URL Settings shows, refuses localhost, and replaces this instance's old localhost notifier instead of adding a second one. ([#185](https://github.com/MickyGX/curatorr/issues/185))
- **Tautulli gap-fill with selected libraries**: Tautulli history rows carry no library ID, so every play was rejected when specific Plex libraries were selected. Curatorr now queries each selected library separately. ([#188](https://github.com/MickyGX/curatorr/issues/188))
- **Node.js security update**: the app image now requires Node 24.22.1 or newer (CVE-2026-111497), and the build fails if an older Node is picked up. ([#187](https://github.com/MickyGX/curatorr/issues/187))
- Imported playlist refreshes are spread across runs, 25 per user per run, oldest due first. A playlist whose refresh fails waits about six hours before retrying, so one broken source no longer holds up the others.
- Auto-refresh labels now appear on M3U, watch-folder and restored-backup playlist cards.
- Added regression tests for the Daily Mix, Tautulli registration and backfill, and bulk and staggered imported playlist refreshes.

## Upgrade Notes

- Update the Curatorr app image and recreate the container as usual. No analyzer update is required.
- A new database column is added automatically on startup.
- New imports keep auto-refresh **Disabled** until an admin sets a default. Existing playlists keep their current setting.
- If Tautulli has a Curatorr notifier pointing at `localhost`, click **Register webhook in Tautulli** once after upgrading to replace it. If plays were missed while the webhook was wrong, use **Backfill history** on the same card.
- Details: `docs/wiki/Playlist-Imports.md#refresh-and-schedules`.
