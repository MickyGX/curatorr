# Curatorr Release Announcement

Curatorr `0.1.42` is out.

Highlights:

- **DJ-style smart playlist ordering** — smart playlists can now sort by BPM, energy, danceability, Camelot wheel, or a new DJ-flow mode for smoother transitions.
- **Better builder UX in light and dark themes** — preset cards, helper text, smart-list layouts, and local-admin dashboard notices now match the active theme properly.
- **Safer personal playlist handling** — duplicate personal playlist rows are prevented, and stale duplicates pointing at the same Plex playlist no longer linger in the UI.
- **Cleaner analyzer sidecar setup** — the release notes and compose guidance now make the required media mount-path alignment explicit so automatic track analysis actually runs.
