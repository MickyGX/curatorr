# Curatorr v0.1.112 Announcement

Curatorr `v0.1.112` is a security release. Upgrade promptly if Curatorr is reachable from outside your home network.

## Highlights

- **Setup wizard locked down**: wizard steps are closed once setup is complete. Before, anyone who could reach Curatorr could create an admin account or get the saved Plex token sent to another server. Artwork images and the system log now need a login, and a damaged `config.json` is no longer replaced with defaults.
- **Jellyfin and Emby webhooks fixed**: webhooks are no longer rejected before their key is checked, so playback tracking no longer relies on polling.
- **Friendlier playlist editing**: dialogs close with Escape and keep keyboard focus inside. The smart playlist builder asks before discarding your changes, and browser pop-ups are replaced with themed dialogs.
