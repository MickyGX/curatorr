# Curatorr Release Announcement

Curatorr `0.1.38` is out.

## Highlights

- **Better track matching** — Last.fm and ListenBrainz playlist seeds now map back to Plex library tracks more reliably when metadata formatting differs between sources.
- **Featured-artist cleanup** — Curatorr now strips common `feat.`, `ft.`, `f/`, and `featuring` variants from artist and title matching.
- **Cleaner title normalization** — remaster, live, remix, and similar trailing title suffixes no longer block otherwise valid track matches.
