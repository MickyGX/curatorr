# Curatorr Release Announcement

Curatorr `0.1.31` is out.

## Highlights

- **Plex Home selection race fix** — duplicate submits on the home-user picker no longer bounce affected users back to `/login`.
- **Non-admin avatar fix** — Blend and blended smart-playlist user avatars now render correctly for regular Plex users, not just the local Curatorr admin preview path.
- **Smart-playlist tier cleanup** — the modal drops the redundant `All` tier option and uses the updated tier-chip layout already rolled into the current UI.
