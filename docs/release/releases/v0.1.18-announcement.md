# Curatorr v0.1.18 Announcement

Curatorr `v0.1.18` is out.

## Highlights

- **Last.fm History Sync** — set your Last.fm username in your User Profile and enable the sync job in Jobs settings. Curatorr will pull your scrobble history from Last.fm, match it against your Plex library, and feed those plays into artist and track scoring — same as plays from Plex or Tautulli.
- **Last.fm History Backfill** — a manual trigger in Jobs settings that works backwards through your full Last.fm history. Runs in batches so you can work through years of history without timeout. Picks up where it left off on each run.
- **Last.fm Station Playlists** — enable Recommended, Mix, and/or Library stations per user in User Profile. Curatorr fetches the tracks Last.fm generates for you, matches them to your Plex library, and keeps the playlists updated on every sync cycle. No API key needed for stations.
- **No more duplicate playlists** — playlist creation now checks Plex first before creating. Resetting or migrating the Curatorr database no longer results in duplicate Crescive/Curative playlists piling up in Plex.
- **Better playlist names in Plexamp** — Crescive and Curative playlists are now named `Crescive Playlist (username)` so the playlist type is visible in Plexamp's truncated list. Existing playlists are renamed in place on first sync after upgrading.
