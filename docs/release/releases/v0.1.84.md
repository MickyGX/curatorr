# Curatorr v0.1.84

## Summary

- **Spotify account linking is more resilient behind proxies and session-sensitive setups.** Curatorr now keeps short-lived server-side OAuth state so the callback can complete even if the browser session is interrupted during the Spotify redirect.
- **Large library refreshes use less memory.** Plex, Jellyfin, and Emby master track refreshes can now stream batches into the database instead of collecting the entire library in memory first.
- **Settings and Playlists avoid unnecessary full-library loads.** Feature preset availability is now calculated directly in SQLite, and folder path discovery is capped to keep very large libraries responsive.

## Fixed

- Fixed Spotify OAuth callbacks that redirected back to Curatorr successfully but left the user disconnected when session data was lost during the redirect flow.
- Added user ownership validation to the Spotify callback path so recovered OAuth state cannot be applied to a different signed-in Curatorr user.
- Changed master track cache refreshes to write track batches as they are fetched from the media server.
- Added follow-up batch updates for Plex mood, album genre, album style, and album mood metadata so streamed refreshes keep the same metadata coverage as the older full-array path.
- Replaced Settings and Playlists feature coverage checks that previously loaded every master track into Node.js memory.
- Capped folder path segment discovery on Settings and Playlists to avoid building huge in-memory path lists for very large libraries.
- Added regression coverage for Spotify OAuth completion after the callback arrives without the original Curatorr browser session.

## Upgrade Notes

- No manual migration is required for this release.
- Users with very large libraries should see lower peak memory use during master track refreshes and less pressure when opening Settings or Playlists.
- Existing Spotify connections are not changed. Users who were unable to connect Spotify should retry the connection after upgrading.
- The folder path picker now samples a capped set of library paths on Settings and Playlists to protect very large installs.
