# Curatorr Release Announcement

Curatorr `0.1.63` is out.

## Highlights

- **Imported playlists can now be converted into editable smart playlists** with inferred audio defaults, recommended chips, and a toggle to switch to all detected genres, moods, and tags from the matched source tracks.
- **Zero-match smart playlists now fail safely** — personal playlists can be saved as drafts instead of getting stuck in a broken state, and those drafts now show up directly on the Playlists page for editing.
- **Playlist, Blend, and dashboard UI spacing got a broad cleanup pass** with clearer Step 2 controls in the wizard and more consistent stat-card spacing across key pages.
