# Curatorr v0.1.55

## Summary

- **DSF/DFF files no longer crash analysis chunks** — the built-in analyzer now skips DSD audio formats (`.dsf`, `.dff`) before attempting to load them, preventing memory exhaustion on low-spec NAS hardware that caused entire analysis chunks to fail with a 500 error.

## Fixed

- Added a pre-load extension check in `analyze-track-features.py` so DSF and DFF files are skipped with a stderr log rather than passed to `librosa.load()`, which falls back to audioread/ffmpeg and can exhaust memory converting large DSD files (~679 MB+) on constrained hardware such as a Synology DS415play. Closes [#58](https://github.com/MickyGX/curatorr/issues/58).

## Upgrade Notes

- No app configuration changes are required.
- Recreate the analyzer container after pulling `mickygx/curatorr-analyzer:latest`.
- DSF/DFF tracks in your library will be silently skipped during analysis; all other formats are unaffected.
