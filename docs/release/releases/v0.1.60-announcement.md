# Curatorr Release Announcement

Curatorr `0.1.60` is out.

Highlights:

- **Smart playlists can now filter by popularity directly** — use album Top 3 filtering or keep only the most popular slice of the current candidate pool with new Step 3 controls.
- **Popularity is now visible across the app** — flame badges mark album top tracks on playlists, tracks, dashboard, history, and blend views.
- **The playlist wizard feels more solid** — popularity controls were moved into the main flow, the advanced cleanup step was simplified, and the modal now keeps a stable size between pages.
