# Curatorr v0.1.75

## Summary

- **Artist collaboration filtering is simpler and broader** so joint credits are now suppressed whenever any credited artist is already known in the library, which reduces noisy standalone artist suggestions for common guest-collaboration patterns.
- **Collaboration detection now treats comma-separated and ampersand-separated credits the same way**, improving coverage for names like `Artist A, Guest B & Guest C`.
- **Named-band safety checks remain in place** so combined-name library matches are still filtered cautiously, avoiding obvious false positives from band components that begin with articles like `The`.

## Fixed

- Simplified the collaboration-credit heuristic to rely on two consistent tests instead of several overlapping special cases.
- Fixed Last.fm and library-affinity artist suggestions so joint credits are filtered as soon as any credited artist is already present in the catalog.
- Added shared parsing for comma-separated and ampersand-separated collaboration names, improving detection for multi-guest credits.
- Reduced missed collaboration filtering for cases like `Doja Cat & The Weeknd`, `Labrinth & Zendaya`, and similar mixed-credit suggestions where only one credited artist needs to exist in the library.
- Preserved the combined-name fallback for library-only joint credits while keeping a guard against named band components such as `The Asbury Jukes`.
- Kept collaboration filtering aligned across both library-derived and Last.fm-derived recommendation candidates.

## Upgrade Notes

- No manual migration is required for this release.
- Artist suggestions will use the simplified collaboration filter the next time Curatorr refreshes or rebuilds discovery recommendations.
- If you were still seeing guest-collaboration credits surface as standalone artist suggestions, those entries should drop out after the next recommendation refresh cycle.
