# Curatorr v0.1.42

## Summary

- **Analysis-aware playlist ordering** — smart playlists can now sort by `BPM`, `energy`, `danceability`, Camelot wheel order, or a new `DJ flow` mode that favors smoother key and tempo changes.
- **Theme and builder polish** — the global playlist builder and personal smart playlist modal now render correctly in both light and dark themes, with improved preset cards, spacing, helper text, and readability.
- **Workflow correctness fixes** — duplicate personal playlist rows, stale light-theme text, and analyzer sidecar path mismatches have been cleaned up so the new analysis workflow behaves more predictably.

## Added

- New smart-playlist sort modes: `BPM low to high`, `BPM high to low`, `Energy low to high`, `Energy high to low`, `Danceability high to low`, `Camelot wheel`, and `DJ flow (Camelot + BPM)`.
- Shared analysis-based ordering for global, personal, and blended smart playlists through the same playlist builder pipeline.

## Fixed

- Fixed feature preset cards so they match the active light/dark theme instead of looking like dark-only panels on day mode.
- Fixed smart-playlist field layouts and modal sizing so the builder remains usable once feature preset controls are enabled.
- Fixed light-theme readability for playlist-builder notes, inline code chips, exclusion filter headers, and the local-admin Plex sign-in banner.
- Fixed duplicate personal playlist rows that could point at the same Plex playlist with different local track counts.
- Fixed the analyzer sidecar production setup requirement so the documented music mount path matches the file paths Curatorr exports to the analysis manifest.

## Upgrade Notes

- If you use the analyzer sidecar, make sure the music library is mounted at the exact same path Curatorr stores for track files. For example, if Curatorr exports `/media/music/...`, the sidecar must also see files under `/media/music/...`.
- The new analysis-based sort modes only affect ordering. Feature filters and preset coverage still decide which tracks are eligible for inclusion.
- If you use the light theme, hard-refresh the browser after upgrading so the updated CSS is loaded.
