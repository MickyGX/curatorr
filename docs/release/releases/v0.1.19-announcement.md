# Curatorr v0.1.19 Announcement

Curatorr `v0.1.19` is out.

## Highlights

- **Last.fm Station Playlist fix** — the Recommended, Mix, and Library playlists from v0.1.18 were silently failing to sync to Plex. This patch fixes the root cause. If you enabled stations in your User Profile and nothing appeared in Plex after a sync, upgrade and run a Smart Playlist Sync — the playlists will be created correctly.
