# Curatorr Release Announcement

Curatorr `0.1.71` is out.

## Highlights

- **Discover has been reworked again** with clearer recent album activity, tighter manual discovery layout, and cleaner artist pipeline actions.
- **Recently Added and Recently Requested album carousels are now built in** and use the same interaction model as manual album discovery.
- **Album popups and Lidarr cleanup are more reliable** with richer track-detail overviews, better artwork fallbacks, and fixes for stale queued artist states.
