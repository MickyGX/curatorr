# Curatorr Release Announcement

Curatorr `0.1.77` is out.

## Highlights

- **Artist collaboration filtering is broader**, catching more duet, `and`, and multi-word joint-credit variations before they appear as standalone recommendations.
- **Playlists page URL imports are fixed**, so import actions now hit the real provider import endpoints instead of preview routes.
- **Discover and playlist workflows are cleaner**, with less collaboration-credit noise and reliable one-click imports for supported URL sources.
