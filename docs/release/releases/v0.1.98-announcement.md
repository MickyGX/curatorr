# Curatorr v0.1.98 Announcement

Curatorr `v0.1.98` fixes scheduled refresh and filtering for M3U imports.

## Highlights

- **M3U auto-refresh unlocked** — choose daily, weekly, or monthly re-matching of the upload stored in Curatorr.
- **Missing tracks can join later** — refresh matches newly available library tracks while retaining source order, playlist name, and artwork settings.
- **M3U in the Imported filter** — uploaded playlists now appear in the correct playlist category.
