# Curatorr v0.1.114 Announcement

Curatorr `v0.1.114` is a bug-fix release.

## Highlights

- **Lidarr auto-add works for the setup admin again**: if your Curatorr setup admin and your Plex account share a username, Curatorr was quietly leaving you out of automatic artist requests. Auto-add, request retries, suggestion rebuilds and Blend syncs now include you.
- **Cleaner "What's new" highlights**: release-note bullets with sub-points now show as one complete highlight instead of being split up.
