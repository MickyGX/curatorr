# Curatorr v0.1.101

## Summary

This release refreshes Curatorr's branding with a new app icon and a full logo on the sign-in pages. It also updates the documentation and screenshot gallery to reflect the current app, including the Music Assistant integration introduced in v0.1.100.

## Changed

- Replaced the previous icon across navigation, browser favicons, setup screens, release and quick-start dialogs, avatar fallbacks, and the web app manifest.
- Added the full Curatorr logo to Plex, Jellyfin, and Emby sign-in pages, with responsive sizing and a subtle glow.
- Bumped the service worker's static cache and updated its asset list for the new icon.
- Refreshed the README, wiki navigation, and screenshots. Added dedicated guides for Music Assistant, Overview, Listening Report, and playlist imports, and updated existing setup, configuration, and troubleshooting guidance.
- Added a local demo environment with fictional listeners and fixture data for capturing documentation screenshots.

## Fixed

- Sign-in pages now allow vertical scrolling so content remains accessible on shorter screens.
- Removed obsolete icon entries from the service worker's precache list.

## Upgrade Notes

- Update the Curatorr app image and recreate the container as usual. No database migration, configuration changes, or analyzer update is required for this release.
- Refresh the page after upgrading. If the old branding remains visible, use a hard refresh so the browser loads the updated assets.
- Music Assistant play tracking was introduced in v0.1.100; this release adds documentation for it without changing playback tracking or playlist generation.
