# Curatorr v0.1.54

## Summary

- **Database migration hardened** — upgrading from older installs no longer crashes on startup due to partial indexes being created against columns that may not yet exist on the user's database.
- **Windows desktop stability** — curatorr startup failures no longer silently kill the Electron process before the tray icon appears; errors are now surfaced as a dialog instead.

## Fixed

- Migration now re-checks column existence before creating partial indexes on `play_events.session_key`, `master_tracks.recording_mbid`, and `track_enrichment.recording_mbid`, preventing `SqliteError: no such column` crashes on upgrade.
- In Electron context, fatal startup errors now throw rather than calling `process.exit(1)`, so the desktop wrapper can catch and display the error instead of disappearing silently.

## Upgrade Notes

- No app configuration changes are required.
- Recreate the app container after pulling `mickygx/curatorr:latest`.
- Windows desktop users who experienced a silent crash on launch should install the updated `curatorr-desktop` release.
