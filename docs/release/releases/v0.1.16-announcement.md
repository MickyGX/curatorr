# Curatorr v0.1.16 Announcement

Curatorr `v0.1.16` is out.

## Highlights

- **Configurable password length** — local Curatorr accounts now respect a `LOCAL_AUTH_MIN_PASSWORD` environment variable. The default stays at `12`, but local network installs can lower this to suit their setup. Curatorr will log a warning at startup if the minimum is set below `12` on an instance that appears to be internet-facing (`TRUST_PROXY=true` or `COOKIE_SECURE=true`).
