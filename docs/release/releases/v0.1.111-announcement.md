# Curatorr v0.1.111 Announcement

Curatorr `v0.1.111` fixes `.m4a` analysis and TIDAL mix import.

## Highlights

- **`.m4a` tracks analyzed again**: the analyzer now decodes AAC/ALAC files with ffmpeg, so they get BPM, key, energy and danceability instead of being skipped. Update the analyzer image to get it.
- **TIDAL mix links work**: pasting a `tidal.com/mix/...` link into the import dialog now previews and imports instead of failing.
