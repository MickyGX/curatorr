# Curatorr v0.1.23 Announcement

Curatorr `v0.1.23` is out.

## Highlights

- **Last.fm Neighbours** — the Neighbours station is now a fourth toggle in User Profile alongside Recommended, Mix, and Library.
- **Per-user backfill** — users can now trigger and reset their own Last.fm Full History Backfill directly from User Profile without needing admin access.
- **Backfill fix for large histories** — a bug caused the backfill to mark history as complete after the first batch regardless of how many scrobbles remained. Users with more than 10,000 scrobbles were affected. Fixed in this release — use the new Reset button in User Profile to clear the old state and re-run.
