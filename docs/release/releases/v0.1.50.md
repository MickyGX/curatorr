# Curatorr v0.1.50

## Summary

- **Packaging hotfix for Docker installs** — this release restores the runtime `wget` binary so existing compose healthchecks keep working and Curatorr stops getting restarted as unhealthy.

## Fixed

- Fixed the main Docker image missing `wget` after the runtime base image changed from Alpine to Debian slim.
- Fixed repeated container restarts on deployments that already use the built-in `wget` healthcheck in Docker Compose.
- Fixed `latest` shipping an image that could appear to load briefly and then disappear as the healthcheck restart loop kicked in.

## Upgrade Notes

- No app configuration changes are required.
- After pulling `mickygx/curatorr:latest`, recreate the `curatorr` container so the corrected image replaces the restart-looping one.
