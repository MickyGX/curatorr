# Curatorr Release Announcement

Curatorr `0.1.45` is out.

Highlights:

- **CI install step fixed** — `package-lock.json` now matches the committed dependency manifest, so GitHub Actions can run `npm ci` successfully.
- **Analyzer release fixes preserved** — the analyzer worker scripts remain tracked in Git, and the analyzer image continues to publish from release tags.
- **AMD64 and ARM64 analyzer images retained** — the sidecar image continues to publish for both `linux/amd64` and `linux/arm64`.
