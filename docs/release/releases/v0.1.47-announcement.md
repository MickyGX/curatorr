# Curatorr Release Announcement

Curatorr `0.1.47` is out.

Highlights:

- **Playlist management got a full polish pass** — playlist cards now show audience badges, support Launcharr-style filtering, and keep disabled playlists separate without leaving carousel gaps.
- **Smarter dedupe and ordering everywhere** — release variants can now collapse across live/remaster/radio-edit style tags, and system plus external playlists now use the same ordering model as the rest of Curatorr.
- **External playlists behave more consistently** — Last.fm and ListenBrainz playlists can be enabled, disabled, filtered, and deleted directly from the playlists page while staying aligned with profile settings.
- **Release packaging is leaner** — `curatorr-analyzer` now keeps the same release version as the main app while only rebuilding when the analyzer image itself changed.
