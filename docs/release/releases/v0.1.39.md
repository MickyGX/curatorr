# Curatorr v0.1.39

## Summary

- **Max track duration filter** — a new Smart Playlist setting (default 10 minutes) excludes overly long tracks from Crescive, Curative, and personal playlists. Long live recordings like Daft Punk's *Alive 1997* will no longer disrupt play-skip scoring by appearing in rotation and being skipped.
- **Smarter metadata matching** — playlist imports now normalise title and artist variants more aggressively before matching tracks back to the Plex library, significantly improving hit rates for Last.fm and ListenBrainz station playlists.
- **Featured-artist cleanup** — titles and artist names that include `feat.`, `ft.`, `f/`, or `featuring` are reduced to the primary match form so the same song is not missed because of metadata formatting differences between sources.
- **Version-suffix cleanup** — trailing title annotations such as `(Remastered)`, `(Live)`, `(from ...)`, and `[Remix]` are stripped during matching to improve seed resolution.

## Added

- Max track duration setting in Settings → Smart Playlists. Tracks longer than the configured limit are excluded from all smart playlist builds. Set to 0 to disable. Defaults to 10 minutes for new installs.

## Fixed

- Long live recordings and medleys appearing in smart playlists and being skipped, gradually lowering the album artist's score unfairly.
- Last.fm and ListenBrainz sourced playlist tracks failing to match library items when the source title includes featured-artist credits that Plex omits.
- Artist-name mismatches where the primary artist is stored cleanly in Plex but appears with appended featured-artist text in upstream metadata.
- Track-title mismatches caused by trailing parenthetical or bracketed release/version labels in the source metadata.

## Upgrade Notes

- No manual database migration is required. The `duration_ms` column is added to the master track cache automatically on first start.
- Trigger a **Refresh Library Cache** (Settings → Library) after upgrading so track durations are populated from your media server. Without this, existing tracks have `duration_ms = 0` and the filter has no effect until the cache is refreshed.
- The default duration limit (10 minutes) applies to new installs only. Existing installs will read the value from their saved config — set it explicitly in Settings → Smart Playlists if you want to activate it.
- Run a manual Smart Playlist Sync after refreshing the library cache to apply both the duration filter and the improved metadata matching immediately.
