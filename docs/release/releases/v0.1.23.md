# Curatorr v0.1.23

## Summary

- **Last.fm Neighbours station** — a fourth Last.fm station playlist option is now available in User Profile alongside Recommended, Mix, and Library. Syncs `https://www.last.fm/player/station/user/{username}/neighbours` as a Plex playlist on every playlist sync cycle.
- **Per-user backfill controls** — the Last.fm Full History Backfill section is now in User Profile. Users can trigger their own backfill batch without needing admin access, and can reset the backfill cursor when their history has been marked complete.
- **Backfill cursor bug fix** — the backfill was incorrectly setting the cursor to `-1` (complete) after processing the first 50-page batch even when more scrobble history remained. Users with more than 10,000 scrobbles would need to reset and re-run. The cursor now correctly advances so each subsequent run continues where the previous one left off.
- **Playlist carousel overflow fix** — the playlists page carousel was expanding the page horizontally rather than scrolling internally. The carousel viewport now constrains to its container width at all screen sizes.
- **Last.fm activity log filters** — the Settings activity log App filter now includes three separate Last.fm entries: Last.fm Tags, Last.fm Sync, and Last.fm Backfill, matching the actual log sources.

## Upgrade Notes

- No database migrations required. Drop-in replacement for v0.1.22.
- Users who ran the backfill before this release and have more than 10,000 scrobbles should use the new **Reset backfill** button in User Profile → Last.fm to clear the incorrect complete state, then run the backfill again.
