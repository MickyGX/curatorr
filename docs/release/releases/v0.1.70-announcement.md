# Curatorr Release Announcement

Curatorr `0.1.70` is out.

## Highlights

- **Playlist import is broader now** with YouTube playlist URL support plus Last.fm and ListenBrainz playlist imports moved into the main Playlists workflow.
- **Imported playlists can now refresh automatically** with per-playlist sync periods for supported imported sources.
- **Discover and overview flows are cleaner** with a clearer artist pipeline vs request queue split, fixed dashboard activity popups, and removal of the dead queue drag handle.
