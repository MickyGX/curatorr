# Curatorr v0.1.48

## Summary

- **This is a packaging hotfix release** — it fixes the main Docker image build so tagged multi-arch publishes complete cleanly again after the `v0.1.47` ARM64 failure.

## Fixed

- Fixed the main Curatorr Docker image failing during ARM64 builds under QEMU when installing native Node dependencies such as `better-sqlite3`.
- Fixed the app container entrypoint so `PUID` and `PGID` overrides still work correctly after moving the image to a Debian-based Node runtime.
- Fixed the release pipeline path for tagged Docker publishes by restoring a stable multi-arch base image for the main app.

## Upgrade Notes

- No app-level configuration changes are required.
- If you pulled `development` while waiting for the release publish to recover, move to `v0.1.48` once it is available.
