# Curatorr Release Announcement

Curatorr `0.1.85` is out.

## Highlights

- **Lidarr catalog expansion no longer stalls on unobtainable albums** — failed grab attempts are now counted and capped, so expansion moves to the next album instead of re-searching daily forever.
- **Playlist sync auto-recovers from a stale Plex machineId** — Curatorr now re-fetches and retries automatically on HTTP 400 rather than failing the sync.
- **Smart playlist builds are faster on large libraries** — getMasterTracks now caches the full scan result in memory and only re-reads when the underlying data changes.
