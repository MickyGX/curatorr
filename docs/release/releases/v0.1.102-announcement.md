# Curatorr v0.1.102 Announcement

Curatorr `v0.1.102` improves Plex playlist recovery and cache refresh reliability.

## Highlights

- **Playlist rebuild recovery**: isolates missing tracks and IDs reassigned to non-music items so valid tracks can still be added.
- **Accurate refresh status**: failed cache refreshes now show errors instead of appearing successful.
- **Safer cache cleanup**: failed or incomplete Plex library scans stop before removing cached entries.
