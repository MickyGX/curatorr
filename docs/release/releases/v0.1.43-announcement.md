# Curatorr Release Announcement

Curatorr `0.1.43` is out.

Highlights:

- **Analyzer sidecar Docker publish fixed** — `mickygx/curatorr-analyzer` now ships with the main release instead of being skipped by the publish workflow.
- **AMD64 analyzer image restored** — the sidecar now publishes for both `linux/amd64` and `linux/arm64`, so x86_64 Docker hosts can use analyzer mode again.
- **Cleaner release builds** — the app image and analyzer image now use separate GitHub Actions cache scopes during multi-arch publishing.
