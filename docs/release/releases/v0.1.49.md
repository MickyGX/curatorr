# Curatorr v0.1.49

## Summary

- **This is a release-automation hotfix** — it fixes analyzer tag reuse so aligned Curatorr releases continue working even when a prior analyzer version tag was never published.

## Fixed

- Fixed Docker publish analyzer reuse logic to probe earlier analyzer tags until it finds one that actually exists on Docker Hub.
- Fixed release-tag publishing when the immediately previous git tag exists in Git but the matching `curatorr-analyzer` image tag does not exist in Docker Hub.

## Upgrade Notes

- No app configuration changes are required.
- This release exists to restore the expected aligned tagging behavior for the Docker images.
