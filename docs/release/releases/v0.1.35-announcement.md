# Curatorr Release Announcement

Curatorr `0.1.35` is out.

## Highlights

- **Smarter playlist controls** — Crescive and Curative now expose cap multipliers, live track-count previews, and more detailed exclusion rules.
- **Folder-based filtering** — playlist builders can filter by folders, excluded libraries, and MusicBrainz recording deduplication using newly captured library file paths.
- **More reliable networking** — Curatorr now prefers IPv4 DNS results first, which helps avoid connection failures in some container and reverse-proxy setups.
