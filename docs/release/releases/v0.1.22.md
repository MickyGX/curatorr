# Curatorr v0.1.22

## Summary

- **Plex Home Users** — Curatorr now supports Plex Home. After signing in with Plex SSO, users with multiple home profiles are presented with a "Who's watching?" profile picker before landing in the app. PIN-protected profiles prompt for the PIN on a separate screen. The home owner's SSO login is used as-is (no redundant PIN step). Each home/managed user gets their own Curatorr session scoped to their Plex identity.
- **Setup wizard Plex prompt** — the server setup wizard now includes a final step (step 6) that prompts the administrator to sign in with their Plex account immediately after server configuration is complete. This replaces the previous behaviour of silently redirecting local admin users to the dashboard, which caused confusion when music features appeared empty.
- **Local admin banner** — when signed in as the Curatorr administrator account (local credentials, no Plex token), a banner is shown at the top of Dashboard, Discover, History, and Playlists explaining that music features require a Plex account, with a direct "Sign in with Plex" link.
- **Firefox confirm-password fix** — the confirm password field in the initial admin setup page and wizard step 1 was marked `autocomplete="new-password"`, which caused Firefox to show its "Suggest a Strong Password" UI on the confirmation field. Changed to `autocomplete="off"` on the confirm field only.
- **Firefox PIN field fix** — the Plex Home PIN entry field used `type="tel"` combined with the webkit-only `-webkit-text-security: disc` CSS property to visually mask input. Firefox does not support this property, leaving the PIN visible in plain text. Field is now `type="password"` with `inputmode="numeric"` for correct cross-browser masking with numeric keyboard on mobile.

## Upgrade Notes

- No database migrations required. Drop-in replacement for v0.1.21.
- Plex Home support is opt-in by behaviour — it only activates when the authenticated Plex account has more than one home user. Single-account installs are unaffected.
- The server setup wizard change only affects new installs or installs where `wizard.completed` is not yet set.
