# Curatorr v0.1.26

## Summary

- **Plex login fix (Plex Home users)** — fixed a race condition in the Launcharr embedded popup flow where the background PIN poll could overwrite the session set by the OAuth callback, causing users to be kicked back to the login screen after selecting a home profile. Fixed with a three-part approach: the PIN poll now detects an in-progress home-user selection and backs off; it also performs the same home-user check as the callback so it can never bypass profile selection; and the home-user selection page sends a `postMessage` to the parent window to stop polling while a profile is being chosen.
- **Master Track Cache handles large libraries** — the Master Track Cache Refresh job no longer crashes with a V8 string-length error on libraries with ~600,000+ tracks. Plex library data is now fetched in pages of 10,000 tracks instead of a single unbounded request, keeping memory well within Node's limits.
- **Plex token optional in setup wizard** — the Plex token field on the wizard's Connect Plex step is now optional. If left blank the wizard saves the URL and moves on; the token is filled in automatically the first time the Plex owner signs in. The step description and field hint explain this clearly, and the empty-library message on the next step distinguishes between "no token yet" and "no music libraries found".
- **Last.fm Loved and Top Tracks playlists** — two new Last.fm playlist types are available in User Settings → Last.fm Station Playlists. *Loved* syncs your manually loved tracks from Last.fm (requires a Last.fm API key in Discovery settings). *Top Tracks* syncs your most-played tracks with a period selector: All Time, Last 7 Days, Last Month, Last 3 Months, Last 6 Months, or Last Year. Both are matched against your Plex library and kept up to date with each playlist sync.
- **Last.fm station cleanup on disable** — disabling a Last.fm station playlist and running a sync now removes the playlist from Plex and hides it from the Curatorr playlists page, instead of leaving an empty or stale playlist behind.
- **Playlist card hover UI** — playlist cards now reveal action icons on hover: an eye icon (centre) to load the playlist's tracks below, a pencil icon (bottom-left, amber) to edit personal playlists, and a three-dot menu (bottom-right) with Rebuild, Edit, and Delete options. Icons are hidden at rest and fade in on hover, with a subtle dark tint over the card art.
- **Multi-select and bulk delete** — a checkbox appears in the top-left corner of each deletable playlist card on hover. Selecting one or more cards shows a selection bar at the top of the panel with a count, a Clear button, and a Delete Selected button.
- **Edit personal playlists** — the pencil icon and the Edit menu item open the Smart Playlist modal pre-filled with the playlist's existing rules (artist tiers, track tiers, genres, moods, tags, top-N, max tracks, sort order). Changes are saved in place and the playlist is re-synced to Plex automatically.
- **Delete restricted to user-created playlists** — the Delete option and the multi-select checkbox are only shown for `personal`, `global`, and `custom` playlists. System-managed playlists (crescive, curative, daily-mix, lastfm-station) have no delete option.
- **Fix: delete targeted the active card** — deleting a playlist always previously deleted whichever card was highlighted, not the card whose button was clicked. Delete now correctly targets the card the button belongs to.
- **Fix: preview returned 0/0 in edit mode** — an Express route-ordering bug caused `GET /api/music/playlists/personal/preview` to be matched as `/:id` with `id = "preview"`, returning 404 and making the preview show 0 artists / 0 tracks. The preview route is now registered before the parameterised route.
- **Removed neutral delta badge** — the orange `=` pill that appeared on playlists with no track-count change is now hidden.

## Upgrade Notes

- No database migrations required. Drop-in replacement for v0.1.25.
- The Plex login fix is automatic — no configuration needed.
- Loved and Top Tracks playlists require a **Last.fm API key** configured in Settings → Discovery. The four existing station playlists (Recommended, Mix, Library, Neighbours) continue to work without one.
- If you have a large Plex music library (hundreds of thousands of tracks), the Master Track Cache Refresh job will now complete successfully. Run it manually from Settings → Jobs after upgrading.
