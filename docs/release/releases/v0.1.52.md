# Curatorr v0.1.52

## Summary

- **Regex filtering is clearer** — advanced regex controls now explicitly describe that they remove matching tracks, which makes `does not match regex` behavior less surprising.
- **Path-based regex filtering is supported** — regex exclusion rules can now target the full file path, which helps with mixed compilation folders and similar library layouts.

## Fixed

- Added `filePath` support to playlist regex exclusion matching so advanced rules can evaluate against the full stored track path.
- Fixed the playlist wizard advanced regex UI to expose file-path targeting alongside track title, album, and artist.
- Fixed the global playlist settings editor so saved file-path rules load back into the builder correctly instead of falling back to the narrower field list.
- Clarified the regex exclusion copy in both the playlist wizard and settings so the exclusion-only behavior is described directly in the UI.

## Upgrade Notes

- No app configuration changes are required.
- Recreate the app container after pulling `mickygx/curatorr:latest` so the updated playlist filtering UI and backend matcher are applied together.
