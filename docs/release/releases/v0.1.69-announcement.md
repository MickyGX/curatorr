# Curatorr Release Announcement

Curatorr `0.1.69` is out.

## Highlights

- **Browser CPU usage is much lower on pages with Music Notes enabled** because the background now stops rendering when disabled and pauses correctly for hidden tabs.
- **Lidarr drift is recoverable now** so deleted upstream albums or artists no longer force a `curatorr.db` reset just to unblock Discover progression.
- **Track and playlist workflows are smoother** with richer track overview popups, pin/unpin actions in the popup itself, and Spotify imports narrowed back to reliable owned-playlist support.
