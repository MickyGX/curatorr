# Curatorr v0.1.79

## Summary

- **Imported playlists are now editable in place** so you can rename supported imported playlists, change their refresh cadence, and let admins promote them to global shared playlists directly from the Playlists page.
- **Plex playlist artwork now has proper lifecycle management** with auto-generated, preserve-existing, and custom-upload modes for personal and global smart playlists, including persisted artwork assets across future syncs.
- **Overview now shows live listening activity** by pulling active media-server sessions into the profile header so users can see what they are currently playing, including paused sessions.

## Fixed

- Added playlist artwork persistence for generated playlists, including database storage for artwork mode, custom artwork assets, preserved Plex artwork snapshots, and playlist audience metadata.
- Added a dedicated stored-artwork service and route so uploaded or preserved playlist images can be safely saved locally and reapplied after playlist rebuilds.
- Extended the smart-playlist wizard and edit flows so Plex users can choose auto-generated artwork, preserve the current Plex artwork, or upload a custom playlist image.
- Added imported-playlist settings editing so supported imported playlists can be renamed, assigned a refresh period, and converted between personal and global audience modes with admin gating.
- Updated playlist-page card metadata, sorting, and badges so imported and global imported playlists are surfaced more clearly and stay aligned with their audience state.
- Added a live Overview `now playing` API and UI block that reads active sessions from Plex, Jellyfin, or Emby and shows the current track, artist, album, artwork, and paused state for the logged-in user.
- Improved background playlist sync diagnostics so automatic Daily Mix and Curatorr sync failures now emit warning logs instead of failing silently.

## Upgrade Notes

- No manual migration is required for this release.
- Curatorr will add the new generated-playlist database columns automatically on startup.
- Playlist artwork preservation and custom artwork application are Plex-specific in this release.
- Admins can now promote supported imported playlists to global visibility from the Playlists page; non-admin users will continue to manage those playlists as personal imports.
