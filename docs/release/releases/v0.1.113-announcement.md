# Curatorr v0.1.113 Announcement

Curatorr `v0.1.113` is a performance fix for large libraries.

## Highlights

- **Playlists page fast on large libraries**: the playlist builder's genre, mood, tag, decade and folder lists are now built in the background and reused until your library changes. On a 530,000-track library the page used to time out after a minute; it no longer has to read the whole library on each visit. Settings → Global Playlists benefits too.
- **Slow Plex no longer holds up the page**: the playlist artwork lookup gives up after 8 seconds and shows fallback artwork instead of leaving the page waiting.
