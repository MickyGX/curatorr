# Curatorr Release Announcement

Curatorr `0.1.61` is out.

Highlights:

- **Import Plex and Spotify playlists directly into Curatorr** — bring in existing playlists as managed custom playlists without rebuilding them by hand.
- **Imported playlists now track what is still missing** — cards show matched and missing counts, and unmatched source tracks stay attached to the playlist for later review or Lidarr actions.
- **The Playlists page is easier to browse on long imports** — missing rows now continue in the main table and the playlist carousel collapses while you scroll through the track list.
