# Curatorr v0.1.11 Announcement

Curatorr `v0.1.11` is out.

## Highlights

- Lidarr artist tagging now works reliably for existing artists, and there is a backfill path for older Curatorr-managed adds.
- Local Curatorr admins no longer generate fake discovery suggestions, while global dashboard and library stats remain intact.
- Plex-auth logins now populate the "Last Curatorr login" field, and history page rendering is more responsive thanks to artwork request caching.
