# Curatorr Release Announcement

Curatorr `0.1.76` is out.

## Highlights

- **Recommendation rebuilds now purge stale collaboration suggestions**, so old joint-credit artist rows are cleaned up automatically after upgrade.
- **The collaboration filter now applies to retained suggestion rows too**, not just newly generated recommendations.
- **Discover gets cleaner faster**, without waiting for stale collaboration credits to age out naturally.
