# Curatorr Release Announcement

Curatorr `0.1.86` is out.

## Highlights

- **Smart playlist wizard polish** — the summary name in Step 5 now updates as you type, and a thumbnail of your saved or pending artwork is shown so you can always see exactly what will be applied on save.
- **Imported playlist source link** — the edit modal for Spotify and YouTube imported playlists now includes a direct link back to the original playlist.
- **Diagnostics and housekeeping** — `starfield-3d.js` moved to the shared head partial for consistent loading, panel styles refactored across seven pages, and structured error logging added for playlist rebuild and Plex sync failures.
