# Curatorr Release Announcement

Curatorr `0.1.81` is out.

## Highlights

- **Overview and Report now lead the app** with dedicated sidebar entries, Overview as the default landing page, the old Dashboard removed from normal navigation, and the admin "Viewing" strip available on both pages.
- **Analytics pages got a broad refinement pass** with Top Playlists and richer popup-driven cards on Overview, plus a featured top-track panel, 52-week heatmap, and cleaner charts on Listening Report.
- **Plex Home auth, smart playlists, Lidarr automation, and Spotify imports are all more reliable** thanks to server-side home-user state, last-played playlist filters, configurable new-artist Lidarr defaults, and fixed large Spotify owned-playlist pagination.
