# Curatorr v0.1.12 Announcement

Curatorr `v0.1.12` is out.

## Highlights

- Crescive and Curative rebuilds now do a real full rebuild, so changes to always-include artists and other playlist inputs are applied immediately.
- Always-include artists now stay aligned with the configured Crescive and Curative favorite-artist percentages instead of being left behind in stale playlist state.
- The README and wiki now include current screenshots for the main app surfaces.
