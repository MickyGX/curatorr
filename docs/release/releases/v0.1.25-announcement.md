# Curatorr v0.1.25 Announcement

Curatorr `v0.1.25` is out.

## Highlights

- **Lidarr queue identity fix** — queued Lidarr requests no longer get stranded when the user is stored under a Plex username in one place and an email in another.
- **Regular-user Lidarr quotas now work** — if you configured weekly `user` quotas such as `1 artist / 2 albums`, manual discovery and background processing now honor those settings.
- **Distinct Artists nav icon** — the Artists sidebar item now uses a music icon instead of matching the Users/profile icon.
