# Curatorr v0.1.18

## Summary

- **Last.fm History Sync** — per-user scrobble history is now pulled from Last.fm on a configurable schedule and matched against your Plex library. Each user sets their Last.fm username in their own User Profile page. Matched plays are recorded as `lastfm_sync` events and contribute to artist and track scoring.
- **Last.fm History Backfill** — a manually triggered job (Jobs settings) that works backwards through a user's full Last.fm history and populates historical play events. Uses a per-user cursor so it can resume across multiple runs without duplication.
- **Last.fm Station Playlists** — three optional Last.fm-generated playlists (Recommended, Mix, Library) can be enabled per user in their User Profile. When enabled, tracks are fetched from Last.fm's station endpoints, matched against the Plex library, and pushed to Plex as `Recommended (Last.fm)`, `Mix (Last.fm)`, and `Library (Last.fm)` playlists. These are refreshed on every playlist sync cycle.
- **Playlist duplicate protection** — playlist creation now searches Plex by title before creating a new playlist. This prevents duplicate playlists appearing in Plex when the Curatorr database is reset or migrated, and handles the legacy naming migration transparently.
- **Playlist naming** — Crescive and Curative playlists are now named `Crescive Playlist (username)` and `Curative Playlist (username)` so the playlist type is visible in Plexamp's truncated playlist list. Existing playlists using the old `username's Crescive Playlist` format are detected and adopted without creating duplicates.

## Upgrade Notes

- **Database migration runs automatically** — three new columns are added to `user_preferences` (`lastfm_enabled_stations`, `lastfm_backfill_cursor` if not already present) via idempotent `ALTER TABLE` on startup. No manual action required.
- **Playlist renaming** — on the first playlist sync after upgrading, Crescive and Curative playlists will be renamed in Plex to the new format. Existing playlists are matched by the old name and updated in place — no duplicates will be created.
- **Last.fm History Sync** is disabled by default. Enable it in Jobs settings and set a Last.fm username in each user's User Profile to activate it.
- No changes to environment variables, config schema, or external service requirements.
