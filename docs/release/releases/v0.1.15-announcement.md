# Curatorr v0.1.15 Announcement

Curatorr `v0.1.15` is out.

## Highlights

- **Last.fm History Sync** — each user can now connect their Last.fm account via User Profile and have their scrobble history backfilled into Curatorr automatically. A new background job handles this on a configurable interval (disabled by default; enable in Settings → Jobs once a Last.fm API key is configured).
- **Plex owner fix** — the primary Plex account (server owner) now appears correctly in Settings → Users → Plex Users. Previously, `plex.tv/api/users` silently excluded the owner from the list, leaving them invisible and unable to be assigned admin. They are now fetched separately and shown at the top, locked as admin.
- **Role resolution fix** — if the Plex server owner logged in and was assigned Normal User instead of Admin, setting the **Plex Admin User** field in Settings → Plex and logging back in will now automatically promote them and correct `admins.json` going forward.
