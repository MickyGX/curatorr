# Curatorr v0.1.22 Announcement

Curatorr `v0.1.22` is out.

## Highlights

- **Plex Home Users** — Curatorr now supports Plex Home accounts. After Plex SSO, users with multiple home profiles see a "Who's watching?" picker. PIN-protected profiles get a separate PIN entry screen. Works the same way as Plex TV apps.
- **Better onboarding** — the server setup wizard now ends with a prompt to sign in with Plex, making it clear that the administrator account is for server management and a Plex login is needed for music features. A banner on music pages also guides local admin users to sign in with Plex.
- **Firefox fixes** — fixed the confirm password field triggering Firefox's password generation suggestion, and fixed the Plex Home PIN entry field showing digits in plain text on Firefox.
