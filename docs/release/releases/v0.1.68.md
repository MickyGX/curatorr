# Curatorr v0.1.68

## Summary

- **Tautulli gap-fill can now do guarded repairs when you want it to** — the daily sync can remain backfill-only by default, or optionally upgrade clearly-short Plex plays when Tautulli has a strong longer match for the same listen.
- **Plex same-track restarts now roll up more reliably** — if a track is quickly restarted from the beginning after an accidental skip or partial play, Curatorr now treats that as a fresh replay instead of swallowing it into the earlier partial session.
- **Release alignment is tighter across the app, Lidarr progression, and the analyzer sidecar** — artist progression now stops correctly once the tracked album is already in the local library, and analyzer script changes now force a fresh `curatorr-analyzer` image release.

## Fixed

- Added guarded Tautulli history repair for existing `plex_webhook` rows, with checks that only allow safe upgrades when the timestamps are close and the Tautulli listen is clearly stronger than the recorded Plex play.
- Moved the guarded Tautulli repair toggle onto the Jobs page so it sits directly with the Tautulli Gap-Fill Sync job it affects.
- Fixed Tautulli nearby/exact/resumed refinement paths so backfill-only mode consistently leaves Plex-recorded rows untouched.
- Fixed Plex same-track replay handling so a new `media.play` from near-zero progress can finalize the previous partial session and start a clean replay path instead of being treated as a resume.
- Tightened the replay continuation check so a fresh replay is not collapsed into the previously finalized row just because Plex reused the same session key.
- Fixed Lidarr artist progression so any successful acquisition recovery result stops further catalog expansion, including local-library/media-server match cases.
- Added regression coverage for Tautulli guarded repair, Plex replay restart handling, and Lidarr progression when the tracked album is already present locally.
- Fixed analyzer Docker publishing so updates to `scripts/analyze-track-features.py` are included in analyzer release detection and rebuild the `mickygx/curatorr-analyzer` image.

## Upgrade Notes

- Recreate both containers after pulling the release so the app and analyzer stay aligned:
  `mickygx/curatorr:v0.1.68`
  `mickygx/curatorr-analyzer:v0.1.68`
- If you use Tautulli as a backup history source, review the new guarded repair toggle in `Settings -> Jobs -> Tautulli Gap-Fill Sync`. Leaving it off keeps the old backfill-only behavior.
- Hard refresh the browser after upgrading. This release moves the guarded Tautulli repair control from the Tautulli settings panel to the Jobs page.
