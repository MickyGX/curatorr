# Curatorr v0.1.24

## Summary

- **Admin user overview page** — a new admin-only `/admin/users` page provides a Plex user comparison view with avatars, role badges, activity, artists/tracks, playlists, Lidarr totals, recent activity, and sign-in history. It is designed to make it clear when an admin is looking at all-user data rather than one Plex account.
- **Local admin user preview mode** — when signed in with the local Curatorr administrator account, music pages now include a Plex user picker in the guidance banner. Admins can switch into a real Plex user context, using that user’s scoped dashboard, history, discover, artists, tracks, and playlists data to troubleshoot exactly what that person sees.
- **Clearer personal vs admin data presentation** — the shared music pages and the admin users page were updated to reduce ambiguity around scope, remove blank fillers where possible, and make cross-user data more explicit. Admin-only comparison data now lives on the dedicated users page instead of relying on a global view on the standard music pages.
- **Multi-range stat layout** — overview stats on Dashboard and on the admin users page now show `7d / 30d / all time` values directly inside the cards and table cells, replacing the previous period toggle pattern for the main overview metrics.
- **Generated playlist title toggle** — Settings now include a global option to append or omit `(username)` from generated playlist names. Changing the toggle immediately renames existing generated playlists in Plex and updates Curatorr’s stored playlist titles so naming stays consistent across Daily Mix, Crescive, Curative, global playlists, personal playlists, and Last.fm station playlists.

## Upgrade Notes

- No database migrations required. Drop-in replacement for v0.1.23.
- Local admin preview mode only appears for the Curatorr local administrator account. Plex-authenticated sessions still see their own personal scoped data as before.
- The new playlist title suffix option defaults to the previous behaviour: usernames remain appended unless you turn the option off in Settings.
