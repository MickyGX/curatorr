# Curatorr v0.1.41

## Summary

- **Automatic track analysis** — Curatorr can now enrich tracks with `BPM`, musical key, Camelot key, energy, and danceability using either a built-in worker or the new optional analyzer sidecar.
- **Feature-driven playlist building** — personal and global playlists now include feature presets, Camelot targeting, live feature-match counts, and coverage-aware preset availability.
- **Shared enrichment pipeline** — MusicBrainz dates, feature analysis results, and Plex loudness all feed the same enrichment store so playlist filtering and sequencing can use one consistent data layer.

## Added

- Analyzer sidecar mode for Docker installs, alongside the built-in worker and custom-command modes, with sidecar health and `/app/data` defaults aligned for container setups.
- Chunked track analysis pipeline with progress updates so large libraries can be processed incrementally instead of as a single long-running request.
- Feature manifest export/import tooling and sidecar docs for automatic BPM/key enrichment workflows.
- MusicBrainz-backed track year and original release date enrichment.
- Plex loudness sync for loudness-aware playlist sequencing.
- Feature presets for both personal and global playlists, including `Club`, `Driving`, `Workout`, `Chill`, `Harmonic`, and `Downtempo`.
- Camelot focus controls supporting multiple keys plus exact, adjacent, relative, and full harmonic matching modes.

## Fixed

- Fixed feature preview counts so the on-screen “Current feature match” number reflects the actual feature-filtered candidate pool instead of the broader playlist preview result.
- Fixed feature filters so tracks missing BPM, energy, or danceability are excluded from feature-dependent presets and rules instead of being treated like zero-valued matches.
- Fixed preset card visuals so the preset picker renders as intentional artwork cards rather than flat placeholder panels.
- Fixed analyzer-sidecar defaults and settings copy so Docker users see the correct `/app/data/...` paths and `http://127.0.0.1:8765` sidecar URL by default.
- Fixed stale running jobs after app restarts by marking interrupted jobs correctly on scheduler startup.
- Fixed Plex loudness sync repeatedly stalling on obvious silence-only tracks.

## Upgrade Notes

- If you use Docker, the recommended analysis mode is `Analyzer sidecar` with:
  - `Feature manifest path`: `/app/data/track-features.json`
  - `Analyzer results path`: `/app/data/track-features.results.json`
  - `Analyzer sidecar URL`: `http://127.0.0.1:8765`
- Feature presets only become useful as feature coverage increases. Tracks without the required enrichment are now excluded from preset matches by design.
- Run `Track Analysis Pipeline` after upgrading if you want BPM/key-based presets to start filling out.
- Run `Plex Loudness Sync` after Plex finishes analyzing more music if you want loudness-aware ordering to improve over time.
