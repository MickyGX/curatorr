# Curatorr Release Announcement

Curatorr `0.1.89` is out.

## Highlights

- **Scheduled playlist rebuild fix** - personal smart playlists are no longer skipped when the scheduler only knows the owner from stored playlist rows.
- **Clearer job status** - Smart Playlist Sync and Rotating Playlist Sync now surface playlist sync failures instead of reporting success while playlists stay stale.
- **Daily Mix and Curatorr covered** - the built-in playlist scheduler now reports failures for both Daily Mix and the Curatorr rotating playlist.
