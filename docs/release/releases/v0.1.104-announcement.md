# Curatorr v0.1.104 Announcement

Curatorr `v0.1.104` adds a play count filter to smart playlists.

## Highlights

- **Play count filter**: keep tracks played at least or at most a set number of times, using each listener's Curatorr play history.
- **Rediscover old favourites**: combine it with "Not played within" and a play count sort for "Repeat Rewind" style playlists, with Curatorr's duplicate handling.
