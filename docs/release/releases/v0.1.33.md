# Curatorr v0.1.33

## Summary

- **Tautulli library filtering fix** — Curatorr now ignores Tautulli webhook and gap-fill events from Plex libraries that are not selected in settings, preventing excluded libraries from leaking into history and playlist logic.
- **Retrospective library cleanup** — removing a Plex library from Curatorr settings now clears that library's derived Curatorr data and rebuilds affected stats, so stale history from removed libraries can be cleaned up without touching Plex or Tautulli.
- **ListenBrainz playlist sync** — users can now sync ListenBrainz generated playlist suggestions into Plex with dedicated user settings, app logging, and log-page filtering.
- **Plex library refresh and settings polish** — Plex settings now support refreshing the available library list, and the Last.fm / ListenBrainz sections are presented more clearly in user settings.
- **Theme and smart-playlist UI fixes** — the user-profile theme picker now matches the main theme settings again, light-mode regressions across blend pickers and smart-playlist modals were fixed, and the Curatorr / playlist rule tables were compacted and cleaned up.

## Upgrade Notes

- No manual database migration is required. This is a drop-in upgrade from v0.1.32.
- Rebuild and redeploy the container so the Tautulli filtering, ListenBrainz sync, and settings/UI fixes are included in the running image.
- If Settings, User Settings, Blend, or Playlists still shows stale styling after upgrade, do one hard refresh so the browser picks up the updated assets.
