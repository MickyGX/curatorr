# Curatorr Release Announcement

Curatorr `0.1.82` is out.

## Highlights

- **The setup admin is now a true recovery account** and can no longer accidentally run the personal music wizard, create personal playlists, or participate in Lidarr automation.
- **Existing installs clean themselves up on startup** by removing stale listening stats, discovery rows, preferences, and related music data that were previously written to the setup admin identity.
- **Background jobs now skip the setup admin consistently** so recommendation rebuilds, playlist syncs, and automation flows only operate on real user identities.
