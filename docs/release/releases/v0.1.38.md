# Curatorr v0.1.38

## Summary

- **Smarter metadata matching** — playlist imports now normalise title and artist variants more aggressively before matching tracks back to the Plex library.
- **Featured-artist cleanup** — titles and artist names that include `feat.`, `ft.`, `f/`, or `featuring` are reduced to the primary match form so the same song is not missed because of metadata formatting.
- **Version-suffix cleanup** — trailing title annotations such as `(Remastered)`, `(Live)`, `(from ...)`, and `[Remix]` are stripped during matching to improve Last.fm and ListenBrainz seed resolution.

## Fixed

- Last.fm and ListenBrainz sourced playlist tracks failing to match library items when the source title includes featured-artist credits that Plex omits.
- Artist-name mismatches where the primary artist is stored cleanly in Plex but appears with appended featured-artist text in upstream metadata.
- Track-title mismatches caused by trailing parenthetical or bracketed release/version labels in the source metadata.

## Upgrade Notes

- No manual database migration is required for this release.
- After upgrading, run a manual Smart Playlist Sync if you want existing generated playlists to pick up the improved match logic immediately.
