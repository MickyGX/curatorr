# Curatorr Release Announcement

Curatorr `0.1.83` is out.

## Highlights

- **Plex playlist artwork is now uploaded directly from Curatorr's stored files** instead of depending on Plex to fetch a Curatorr-hosted artwork URL later.
- **Imported and generated playlists are more resilient when Curatorr is offline**, including the reported reboot case involving Spotify-imported playlists on Plex.
- **The safer artwork path keeps a compatibility fallback** so older Plex behavior can still use the previous URL-based update flow if needed.
