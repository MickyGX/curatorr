# Curatorr v0.1.98

## Summary

M3U/M3U8 imports can now use daily, weekly, or monthly auto-refresh. Curatorr re-matches the uploaded source stored in its database against the current library cache, allowing previously missing tracks to join the managed playlist as they become available.

## Fixed

- Removed the M3U-only restriction that disabled the Auto-refresh selector in the imported playlist editor.
- Fixed the imported playlist settings API forcing M3U refresh schedules back to Disabled when saving.
- Corrected M3U playlist classification so personal M3U imports appear under the Imported filter. Global M3U playlists retain their global classification.
- Updated the Imported filter description to include M3U playlists.
- Added regression coverage for manual refresh and all three schedule intervals, including newly matched tracks returning to their original source positions and preservation of playlist identity, name, source content, filename, and artwork settings.

## Upgrade Notes

- No database migration or analyzer update is required for this release.
- Existing imports remain on their saved schedule. Open the playlist's **Edit** dialog, choose an **Auto-refresh** interval, and save to enable scheduled re-matching.
- Refresh uses the uploaded M3U content stored in Curatorr's database. It does not need a source URL or continued access to the original file on your computer.
- New library tracks must be present in Curatorr's master track cache before manual or scheduled refresh can match them. Refresh the master track cache after adding music if needed.
- Imports created before v0.1.97 may lack stored source content and need to be re-imported once before refresh can work.
