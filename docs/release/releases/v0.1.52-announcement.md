# Curatorr Release Announcement

Curatorr `0.1.52` is out.

Highlights:

- **Regex exclusion UX is clearer** — the advanced playlist UI now explains that regex rules remove matching tracks, so `does not match regex` behaves less unexpectedly.
- **Full file-path regex support** — advanced playlist filtering can now target the full stored track path, which is useful for mixed compilations and similar folder layouts.
