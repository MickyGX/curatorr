# Curatorr v0.1.66

## Summary

- **Discover now verifies Lidarr monitoring instead of trusting catalog metadata** — Manual Discovery treats unmonitored Lidarr albums as requestable, completed requests record monitoring confirmation, and completed queue rows can repair monitoring if Lidarr later shows the album as unmonitored.
- **Force Search is available from Discover queue rows and monitored album cards** — Curatorr can re-monitor the target album when needed, trigger a Lidarr album search, and keep the current Discover search/scroll context instead of reloading the page.
- **Smart-playlist dedupe is easier to audit and tune** — the existing MBID and fuzzy artist/title dedupe toggles now have optional duration, variant, and live-album guards, and the wizard can copy or download a CSV showing which duplicate tracks were skipped and why.

## Fixed

- Fixed Manual Discovery album status labels so Lidarr metadata without monitoring no longer appears as already added.
- Fixed completed Lidarr queue rows so Curatorr re-checks Lidarr monitoring and attempts to re-monitor the selected album instead of silently leaving a completed row with no monitored album.
- Fixed request completion logic so album monitoring is verified after calling Lidarr, and the request detail records that confirmation.
- Added `Force search` to the Discover queue three-dot menu for completed and failed Lidarr requests with album IDs.
- Added `Force search` to monitored album-card three-dot menus in Manual Discovery while keeping unmonitored albums on the normal `Add album` path so quota/request tracking is not bypassed.
- Fixed queue force search so it updates the row state without forcing a full-page reload.
- Fixed Discover album card dates so ISO release dates render as plain dates rather than showing the `T00:00:00Z` suffix.
- Fixed the release welcome popup so long release notes scroll to the true end without changing shared modal hero behavior used elsewhere.
- Added smart-playlist dedupe guards for duration within 5 seconds, likely distinct live/demo/acoustic/remix/instrumental versions, and live album/subformat metadata where present.
- Added duplicate-report data to personal and global playlist preview endpoints.
- Added `Copy CSV` and `Download CSV` actions to the smart-playlist wizard preview so dedupe matches can be inspected outside Curatorr.

## Upgrade Notes

- Recreate the app container after pulling `mickygx/curatorr:latest`.
- Hard refresh the browser after upgrading. This release changes Discover and playlist wizard JavaScript/CSS.
- Existing Lidarr queue rows that were marked completed before this release may be repaired on the next Discover reconciliation or by using the new Force Search action when a Lidarr album ID is available.
- The new dedupe guards are opt-in. Existing playlist rules keep their previous dedupe behavior unless you enable the additional toggles.
