# Curatorr v0.1.97 Announcement

Curatorr `v0.1.97` is out with refreshable M3U imports, a Tautulli Gap-Fill API fix, and safer built-in analyzer runs for very long audio files.

## Highlights

- **M3U imports can refresh** - new `.m3u` and `.m3u8` imports store their source so Curatorr can rebuild matches later.
- **Playlist refresh reaches Plex** - the Playlists page now sends M3U imports through the real refresh flow and replaces the Plex playlist in source order.
- **Long-file analyzer protection** - built-in analysis now decodes a capped slice of audio by default, reducing OOM risk on multi-hour files while keeping the cap configurable.
