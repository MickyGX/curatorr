# Curatorr Release Announcement

Curatorr `0.1.32` is out.

## Highlights

- **Blend header controls restored** — the version badge and theme toggle are back on the Blend page.
- **Blend layout polish** — spacing, helper text sizing, and the paired blended artists / tracks panels are more consistent.
- **Carousel edge gutter fix** — Playlists and Blend now keep a proper left inset before the first carousel card, matching the intended dashboard styling.
