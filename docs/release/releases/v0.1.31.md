# Curatorr v0.1.31

## Summary

- **Plex Home selection race fix** — Curatorr now blocks duplicate submits on the "Who's watching?" picker and coalesces repeated profile-selection requests on the server, preventing a second fast submit from knocking the user back to `/login`.
- **Non-admin avatar fix** — Blend and blended smart-playlist user pickers now resolve live Plex and Plex Home profile avatars for regular Plex users instead of only showing initials outside local-admin preview mode.
- **Smart-playlist tier cleanup** — the modal now removes the redundant `All` tier chips and keeps the Artist Tier / Track Tier controls in a tighter single-purpose layout under their labels.

## Upgrade Notes

- No database migration required. Drop-in replacement for v0.1.30.
- Rebuild and redeploy the container so the updated Plex Home login flow and avatar lookups are included in the running image.
- If a browser still shows stale Blend or Playlists assets after upgrade, do one hard refresh.
