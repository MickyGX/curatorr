# Curatorr v0.1.12

## Summary

- Fixed Crescive and Curative manual rebuilds so they now fully regenerate from the latest user settings instead of only applying incremental evolution to the existing playlist state.
- Fixed always-include artists so they are re-evaluated against the configured favorite-artist percentages during rebuilds, which keeps forced artists aligned with Crescive and Curative track allocation settings.
- Refreshed the README and wiki with current screenshots for dashboard, login, discovery, and playlists, and added a generated PNG app icon for documentation and release assets.

## Upgrade Notes

- Rebuild and redeploy Curatorr so the generated playlist rebuild fix is included in the running image.
- Rebuild Crescive and Curative once after upgrading if you changed always-include or never-include artists and want the live playlists regenerated from the latest settings immediately.
- Hard refresh the README/wiki pages or republish the wiki after upgrade if you want the new screenshot-backed docs to appear in downstream copies.
