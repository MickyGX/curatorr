# Curatorr Release Announcement

Curatorr `0.1.84` is out.

## Highlights

- **Spotify linking is more reliable** when redirects lose the original Curatorr session.
- **Large library refreshes use less memory** by writing media-server track batches as they are fetched.
- **Settings and Playlists are lighter on huge libraries** thanks to SQL-based feature checks and capped path discovery.
