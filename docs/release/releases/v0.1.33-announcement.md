# Curatorr Release Announcement

Curatorr `0.1.33` is out.

## Highlights

- **Excluded-library Tautulli fix** — gap-fill and live Tautulli events now respect the Plex libraries selected in Curatorr, so excluded libraries no longer pollute history.
- **ListenBrainz playlist suggestions** — users can sync ListenBrainz generated playlists into Plex with separate settings and dedicated activity logging.
- **Settings and theme polish** — Plex library refresh, cleaner Last.fm vs ListenBrainz separation, restored profile theme controls, and a batch of day-theme / blend-picker UI fixes are all included.
