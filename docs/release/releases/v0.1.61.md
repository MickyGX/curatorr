# Curatorr v0.1.61

## Summary

- **Plex and Spotify playlists can now be imported into Curatorr** — existing Plex playlists/collections and connected Spotify playlists can now be pulled in as managed custom playlists, so imported lists sit alongside Curatorr-built playlists instead of living outside the app.
- **Imported playlists now carry their missing tracks with them** — imported playlist cards show both matched and missing counts, and the playlist page keeps unmatched source tracks attached to the imported playlist so you can review what is still missing from your library.
- **Playlist browsing is smoother on long imports** — the Playlists page now merges imported missing rows into the main track table and collapses the playlist carousel while you scroll through the list, making imported playlists behave more like a single continuous page instead of two stacked sections.

## Fixed

- Added Spotify connection support in User Settings plus playlist browsing, previewing, and matched-track import into Curatorr-managed custom playlists.
- Added Plex import support for existing playlists and music collections, while filtering Curatorr-managed playlists out of the import source list to avoid circular imports.
- Imported playlists now persist source metadata and support `Refresh import`, allowing Curatorr to re-read the original Plex or Spotify source, rematch against the current library, and update both matched tracks and missing counts after new music is added.
- Imported playlist cards now use a dedicated imported badge/icon, display `tracks • missing`, sort after personal playlists, and can be filtered separately from personal, system, external, and global playlists.
- Missing source tracks now persist against the imported playlist and can be selected in-place for later actions rather than being thrown away after the import preview closes.
- Added playlist-page actions to queue selected missing rows for Lidarr review or add them directly to the Lidarr queue, preserving album titles where available instead of collapsing everything to a generic `Curatorr pick`.
- Fixed the imported-playlist layout so missing rows now continue directly under the matched tracks in the same table, and the carousel auto-collapse/expand behaviour works against the actual desktop table scroller instead of only the page scroll position.
- Added system playlist renaming so Curatorr, Daily Mix, Crescive, and Curative playlists can use a manual Plex title override instead of the default generated name.

## Upgrade Notes

- Recreate the app container after pulling `mickygx/curatorr:latest`.
- Spotify import requires app-level Spotify API credentials (`SPOTIFY_CLIENT_ID` and `SPOTIFY_CLIENT_SECRET`) plus a matching redirect URI in the Spotify developer app before users can connect their own accounts.
- Existing imported playlists created before source metadata and missing-row persistence were added may not show missing-source state until they are re-imported or refreshed once.
- Popularity-based playlist controls remain Plex-only for now because they still rely on Plex `ratingCount`.
