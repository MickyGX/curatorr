# Curatorr Release Announcement

Curatorr `0.1.78` is out.

## Highlights

- **Lidarr progression no longer gets stuck after confirmed downloads**, so artists can continue through catalog expansion and completion.
- **Artists should now reach `catalog_complete` reliably** after Lidarr import succeeds instead of sitting in intermediate states.
- **Media-server-only matches still stay guarded**, so Curatorr does not advance catalog state before Lidarr has really imported the files.
