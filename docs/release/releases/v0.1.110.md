# Curatorr v0.1.110

## Summary

This release adds Plex History Sync, so plays Curatorr never saw, such as tracks played offline in Plexamp, now count towards your history, stats and playlists.

## Added

- **Plex History Sync** job in **Settings → Jobs → Listening history**. It reads Plex's own play history and adds plays Curatorr doesn't already have.
- The main case is offline listening. Plexamp plays downloaded tracks without a server connection, so no Plex webhook fires and Tautulli sees no stream. When Plexamp reconnects it reports those plays to Plex, and this job picks them up.
- It also catches online plays a webhook missed, for example while Curatorr was restarting.
- The job runs every 6 hours and checks the last 7 days. The **Backfill** control on the job row runs it once over up to 365 days to recover older plays.

## How plays are matched

- A Plex play is skipped if Curatorr already has a play of the same track by the same user at about the same time, from a webhook, Tautulli, Last.fm or an earlier run. Running the job again never adds a play twice.
- Each recorded play matches only one Plex entry, so a track played twice in a row is still counted twice.
- Plex sometimes logs one play twice a few seconds apart; those are counted once.
- Plays from the last 20 minutes, and tracks still playing, are left for the next run so a live play isn't counted twice.

## Notes and limits

- Plex history records that a track was played, not how long for. Imported plays count as full listens, the same as Last.fm scrobbles, so a skip made offline is not counted as a skip.
- Plex marks a play when the track is about 90% through. Curatorr estimates the start time from that and the track length.
- Plex only. Jellyfin and Emby keep no per-play history, so the job shows as unavailable there.

## Upgrade Notes

- Update the Curatorr app image and recreate the container as usual. No analyzer update is required.
- No database changes. The job is enabled by default and first runs shortly after startup. Run **Backfill** once if you want to recover offline plays from further back than 7 days.
- Details: `docs/wiki/Integrations.md#plex-history-sync` and `docs/wiki/Configuration.md#jobs`.
