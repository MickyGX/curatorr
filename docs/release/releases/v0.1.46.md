# Curatorr v0.1.46

## Summary

- **Smart playlist creation now runs through one wizard** — personal, blend, and global playlists now use the same multi-step builder, and editing existing playlists reopens that wizard with the current settings prefilled.
- **Settings-derived starters added** — the wizard now includes `Curatorr`, `Crescive`, and `Curative` starting points, plus a new `Wake Up` audio profile and stronger preset defaults that seed both audio and content filters.
- **Analyzer batches are more resilient** — unreadable audio files are skipped instead of crashing the whole analysis chunk, and analyzer-side failures now surface clearer error detail.

## Added

- Added wizard starters for `Curatorr`, `Crescive`, and `Curative`, using the current smart-playlist settings as editable baselines.
- Added a `Wake Up` audio profile for brighter early-morning playlists.
- Added wizard auto-naming based on target, starting point, and audio profile, with manual override on the final step.
- Added a separate eligible-pool preview alongside the final capped playlist preview so filter changes are easier to understand.

## Changed

- Replaced the old flat personal playlist editor with the main wizard for both create and edit flows.
- Replaced the old settings-page global playlist builder with a `Create Playlist` handoff into the main wizard, and routed global edits there too.
- Reworked content filtering around tri-state pills, accordion sections, include-mode toggles, and admin-only advanced folder/regex controls.
- Moved playlist naming to the finish step and aligned the summary layout for a cleaner final review.

## Fixed

- Fixed blend selections being wiped when changing wizard starting points.
- Fixed stale audio preset state and out-of-order preview responses causing incorrect wizard preview counts.
- Fixed section collapse behavior in genres, moods, tags, seasonal filters, tiers, and advanced folder filters.
- Fixed Crescive and Curative starter previews defaulting to the whole library instead of a realistic starter size.
- Fixed Curatorr preview artist counts being misleading by reporting counts from the final capped selection.
- Fixed analyzer batches aborting on unreadable tracks by skipping bad files and continuing the chunk.

## Upgrade Notes

- Global playlist creation and editing now route through the playlists-page wizard instead of the older settings inline builder.
- If you rely on analyzer batches, deploy `v0.1.46` or later so unreadable media files no longer fail the entire chunk.
