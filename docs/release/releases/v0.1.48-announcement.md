# Curatorr Release Announcement

Curatorr `0.1.48` is out.

Highlights:

- **Packaging hotfix for Docker users** — this release fixes the main app image build so tagged multi-arch Docker publishes complete cleanly again.
- **ARM64 publish path restored** — the main Curatorr image now avoids the Alpine/QEMU native-module install path that broke the `v0.1.47` release build.
