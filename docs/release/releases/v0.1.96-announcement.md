# Curatorr v0.1.96 Announcement

Curatorr `v0.1.96` is out with a Lidarr monitoring fix, a smoother M3U import dialog, and CI/runtime cleanup for Node 24.

## Highlights

- **Lidarr `new` monitoring fixed** - Curatorr now sends `new` only to Lidarr's `monitorNewItems` field and maps the separate add-time monitor field to `none`, so artist adds no longer fail.
- **M3U imports feel steadier** - the editable playlist-name field stays above the preview after tracks load.
- **Node 24 checks are stable** - CI is pinned to the runtime Node major with the compatible `better-sqlite3` 12.x addon.
