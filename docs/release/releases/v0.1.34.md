# Curatorr v0.1.34

## Summary

- **Discovery album workflow upgrade** — manual discovery album cards and Curatorr picks now use playlist-style controls for select, view, and quick add actions, with richer status icons, ordered fallback album previews, and album overview modals that can show track lists and multi-disc group headings.
- **Global playlist editing and playlist controls** — global playlists can now be edited directly from Settings and the Playlists page, and Crescive / Curative generated playlists can be enabled or disabled independently.
- **Recent play consolidation fixes** — repeated listens of the same track now consolidate more reliably across pause/resume sequences and metadata drift, the dashboard recent-plays panel now uses the rolled history feed, and merged listens recalculate the displayed Curatorr tier from the accumulated duration.
- **Plex webhook cleanup** — re-registering the Plex webhook now prunes stale Curatorr `/webhook/plex` URLs, reducing `invalid or missing key` failures after a base URL or webhook secret change.

## Upgrade Notes

- No manual database migration is required. This is a drop-in upgrade from v0.1.33.
- Rebuild and redeploy the container so the updated discovery controls, playlist editing flow, webhook pruning, and recent-play consolidation logic are included in the running image.
- If Discover, History, Dashboard, Playlists, or Settings still shows stale UI after upgrade, do one hard refresh so the browser picks up the new CSS and JavaScript assets.
