# Curatorr Release Announcement

Curatorr `0.1.68` is out, with a matching `curatorr-analyzer` release.

## Highlights

- **Tautulli gap-fill now has an optional guarded repair mode** so clearly-wrong short Plex listens can be upgraded when Tautulli has a close, longer credible match.
- **Plex replay rollup is safer** so quickly restarting the same track from the beginning no longer gets trapped as the earlier skipped or partial session.
- **Lidarr progression and analyzer releases are both tighter** — Curatorr now stops expansion once the tracked album is already in your library, and analyzer script fixes now force a fresh sidecar image release.
