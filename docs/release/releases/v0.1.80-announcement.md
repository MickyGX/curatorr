# Curatorr Release Announcement

Curatorr `0.1.80` is out.

## Highlights

- **Listening Report is live** with a dedicated report page for period-led listening analytics, weekly comparisons, chart-heavy summaries, and richer personal listening stats.
- **Album-level metadata filters now work end-to-end**, so album genres, styles, and moods can be imported, cached, reviewed in the wizard, and used in smart-playlist rules separately from track metadata.
- **The content wizard is clearer about metadata sources**, keeping media-server metadata, Curatorr-derived filters, and Last.fm tags distinct while also fixing a report rendering error on `/report`.
