# Curatorr v0.1.71

## Summary

- **Discover is much easier to read and act on** with a stronger split between manual discovery, recent album activity, the artist pipeline, and the request queue.
- **Recent album activity is now first-class on Discover** thanks to new Recently Added and Recently Requested carousels that use the same album-card interactions as manual discovery.
- **Album and request state is more trustworthy** because Lidarr-backed album popups now show richer track details and stale request cleanup no longer leaves artists stuck in queued states.

## Fixed

- Added `Recently Added Albums` and `Recently Requested` carousels to the Discover page.
- Reused the manual-discovery album-card overlay/actions for the new recent album carousels so view, add, force search, and exclude actions behave consistently.
- Fixed recent album overview popups so they respect the card state instead of contradicting it with `not in library` messaging for already-added items.
- Fixed recent album overview fallbacks so carousel cards can pass thumb/status context into the shared overview renderer.
- Fixed Lidarr album overview resolution so Discover album popups use the full Lidarr album path whenever an album id is available, restoring track lists and richer album details.
- Fixed missing artwork in recent album popups by falling back to the card image when the overview payload does not provide its own poster.
- Improved Discover artist pipeline dropdown behavior so the top-row menu can open downward when needed and no longer clips the first action off-screen.
- Restored a simpler artist pipeline action menu with the expected `Add to library` / `Retry add to library` and `Dismiss` actions.
- Tightened Manual Discovery layout spacing so the explainer and search bar align with the artist/media strip below.
- Fixed request deletion so completed stale Lidarr requests can be removed and do not falsely report success while staying in place.
- Fixed stuck artist-pipeline rows by resetting `queued_for_lidarr` suggestions back to the appropriate status when a failed or stale request is deleted.
- Added regression coverage for stale Lidarr request removal and stuck pipeline recovery.

## Upgrade Notes

- Recreate the Curatorr container after pulling this release:
  `mickygx/curatorr:v0.1.71`
- Hard refresh the browser after upgrading. This release changes shared Discover page frontend assets, menu behavior, and album overview handling.
- If you have artists stuck in the pipeline from stale Lidarr requests, retrying or deleting those requests after upgrading should now clear the stuck queued state correctly.
