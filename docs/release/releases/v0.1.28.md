# Curatorr v0.1.28

## Summary

- **Jellyfin and Emby support** — Curatorr now works with Jellyfin and Emby as primary media servers alongside Plex. The setup wizard, settings, smart playlists, playback tracking, history, artist scoring, and Discover all work end-to-end with Jellyfin and Emby.
- **Genre normalisation** — genre data from Jellyfin (which stores genres as semicolon-joined strings) is split and normalised at every layer: ingestion, scoring, the wizard genre picker, and all discovery and tracks templates. Numeric genre IDs are filtered out automatically.
- **Jellyfin playlist track loading performance** — the Jellyfin user ID lookup is now cached with a 1-hour TTL, removing a redundant API round-trip on every paginated tracks request and significantly reducing load time.
- **Configurable session cookie name** — a new `SESSION_COOKIE_NAME` environment variable allows the session cookie name to be overridden. Useful when running multiple Curatorr instances on the same host, where browser cookie scoping by domain (not port) would otherwise cause session collisions between containers.
- **Plex-specific UI cleanup** — the Playlist Account Maintenance settings card is now hidden for Jellyfin and Emby users. User profile notes reference the correct media server name rather than hardcoding Plex.

## Upgrade Notes

- No database migrations required. Drop-in replacement for v0.1.27.
- If you run a dev and production container on the same host, set `SESSION_COOKIE_NAME` to a unique value per container to prevent session conflicts.
