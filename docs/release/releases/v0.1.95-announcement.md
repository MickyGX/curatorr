# Curatorr v0.1.95 Announcement

Curatorr `v0.1.95` is out with M3U playlist import, ordering that survives the import, and a move to the Node 24 runtime.

## Highlights

- **Import your M3U playlists** - drop in a `.m3u` or `.m3u8` file and Curatorr matches it to your library by file path first, then by `Artist - Title` metadata, with a preview of what matched before anything is created.
- **Imported playlists keep their order** - playlist tracks now remember the position they had in the source playlist instead of falling back to storage order.
- **Node 24 runtime** - the image moves to `node:24-alpine` with `better-sqlite3` 12; existing data volumes are used unchanged.
