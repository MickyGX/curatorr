# Curatorr v0.1.40

## Summary

- **New Curatorr rotating playlist** — added a new generated playlist type called `Curatorr`, designed as a configurable rotating mix that blends familiar favourites with discovery tracks.
- **Daily Mix upgrade** — Daily Mix is now fully configurable instead of fixed-size, with controls for favourites, suggestions, fresh tracks, total size, artist caps, cooldowns, and filters.
- **Shared rotating-playlist sync flow** — Daily Mix and Curatorr now use the same generated-playlist sync path, so rebuilds, scheduled syncs, and stored playlist membership behave consistently.
- **Settings and onboarding integration** — added dedicated Settings cards for Daily Mix and Curatorr, per-playlist enable toggles, rebuild support in the playlist UI/API, and optional Curatorr creation during onboarding.

## Added

- New `Curatorr` playlist type with support for target track count, discovery ratio, per-artist caps, repeat cooldown, and track filters.
- Expanded Daily Mix settings in Settings → Smart Playlists so users can tune composition and size instead of relying on the old fixed build.
- Shared selection-playlist sync handling for Plex and Jellyfin/Emby-backed generated rotating playlists.
- Playlist-page and wizard support for Curatorr, including rebuild support and automatic creation during onboarding when enabled.

## Fixed

- Fixed generated rotating playlist handling so Curatorr is treated as a first-class generated playlist across jobs, playlists UI, rebuild flows, and stored playlist membership updates.
- Fixed settings persistence so Daily Mix and Curatorr can be saved as intentionally small rotating playlists without being clamped back to older minimum sizes.
- Fixed missing strict-match defaults in user preferences that could break ListenBrainz-related preference saves and fallback test paths on first write.

## Upgrade Notes

- Review Settings → Smart Playlists after upgrading. Daily Mix and Curatorr now have their own cards and can be enabled, disabled, or tuned independently.
- If you want compact rotating playlists, you can now set very small track counts directly in Settings for both Daily Mix and Curatorr.
- Run a manual rebuild or wait for the rotating-playlist sync job to refresh Daily Mix and Curatorr using the new settings.
