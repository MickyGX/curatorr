# Curatorr v0.1.47

## Summary

- **Playlist cards are much more manageable** — they now show audience badges, support Launcharr-style filtering, and keep disabled playlists visually separate without breaking carousel layout.
- **Smart playlist dedupe and ordering are broader** — release variants can be collapsed more aggressively, and system plus external playlists now share the same ordering model as personal, blend, and global playlists.
- **External playlist handling is cleaner** — Last.fm and ListenBrainz playlists can be enabled, disabled, filtered, and deleted from the playlists page while staying aligned with profile-level settings.

## Added

- Added playlist audience badges for personal, external, blend, global, and system playlists.
- Added Launcharr-style playlist header filters for playlist type and enable status.
- Added card-level and bulk enable/disable actions for playlists, including disabled-state styling and Plex removal/re-add flows.
- Added external playlist badges, ordering controls, and source-aware enable flows so Last.fm and ListenBrainz playlists behave more like first-class Curatorr playlists.
- Added fuzzy release-variant deduplication that ignores tags like live, radio edit, mono, remaster, and mix while keeping the highest-rated copy.
- Added shared base-sort plus final-ordering controls for system and external playlists alongside the existing smart-playlist builders.

## Changed

- Changed playlist ordering so cards group by playlist type with active playlists first and disabled playlists moved to the right within the same type order.
- Changed playlist header controls to use the same themed square-button styling as the rest of the app, including compact `+` actions for playlist creation.
- Changed About and release-note support links to include the new Reddit community alongside Discussions and Discord.
- Changed Docker release automation so `curatorr-analyzer` only rebuilds when its own image inputs change and otherwise reuses the previous analyzer image under the new aligned release tag.

## Fixed

- Fixed disabled playlists getting stuck undeletable after being removed from Plex.
- Fixed external playlists requiring both profile toggles and playlist-page enablement by keeping both paths in sync.
- Fixed playlist filtering leaving a visible left gap after the card set shrank.
- Fixed system playlist icon rendering and playlist-card badge alignment.
- Fixed analyzer-side unreadable-track reporting so analysis failures surface more useful context during release validation.

## Upgrade Notes

- External playlists can now be managed directly from the playlists page, but the underlying source integrations still need valid Last.fm or ListenBrainz credentials in the user profile.
- Release automation now supports optional Reddit posting; leave the Reddit secrets unset if you do not want that step to run.
