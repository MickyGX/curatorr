# Curatorr v0.1.93

## Summary

- **Production dependency audit is clean.** This release refreshes the Express 4 transitive dependency stack in `package-lock.json` so production installs no longer report the remaining high/moderate `npm audit` findings.
- **Security-only scope.** The update is limited to dependency metadata and patched package resolutions; Curatorr application behavior is unchanged.

## Fixed

- Updated the lockfile resolution for `express` from `4.22.1` to `4.22.2`.
- Updated Express transitive dependencies to patched versions, including `body-parser` `1.20.6`, `path-to-regexp` `0.1.13`, and `qs` `6.15.3`.
- Refreshed related transitive lockfile entries pulled in by the audit fix, including `form-data`, `hasown`, `side-channel`, and `side-channel-list`.
- Verified `npm audit --omit=dev --audit-level=high` reports no vulnerabilities.

## Upgrade Notes

- No configuration or database changes are required.
- Rebuild or redeploy with the updated lockfile so production installs resolve the patched dependency versions.
