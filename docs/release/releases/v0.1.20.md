# Curatorr v0.1.20

## Summary

- **Last.fm Station Playlist track matching fix** — tracks returned by Last.fm's Recommended, Mix, and Library station endpoints were not matching against the Plex library due to a camelCase/snake_case mismatch in the internal lookup (`artistName`/`trackTitle`/`ratingKey` vs `artist_name`/`track_title`/`rating_key`). All three station playlists now populate correctly with matched tracks.
- **Last.fm Station Playlist duplicate fix** — when `ensureGeneratedPlaylist` searched Plex for an existing playlist to adopt, it incorrectly applied the Crescive/Curative legacy title fallback (`"username's Curative Playlist"`) to station playlist types, causing all three station playlists to match the existing Curative Playlist and share its Plex ID. Station playlists now only match on their own exact title.

## Upgrade Notes

- No database migrations. Drop-in replacement for v0.1.19.
- If you ran v0.1.18 or v0.1.19 and have Last.fm station playlists configured, the bad shared-ID records will be cleaned up automatically on the next Smart Playlist Sync — three correctly named playlists will be created in Plex.
