# Curatorr v0.1.80

## Summary

- **Listening Report is now a first-class destination** with a new `/report` page inspired by listening-report style analytics: period-led summary cards, weekly playback comparisons, top artists/albums/tracks, discovery callouts, music ratio, listening fingerprint, top tags, music-by-decade, listening clock, tier breakdown, and quick facts.
- **Album-level metadata is now usable throughout smart playlists** so album genres, album styles, and album moods can be stored from the media server, inferred from imported playlists, reviewed in the wizard, and applied during playlist preview/build alongside the existing track-level filters.
- **Content filters are now easier to reason about** because the wizard separates media-server metadata, Curatorr-derived filters, and Last.fm tags into clearer sections with better labels, imported-content hints, and missing-metadata guidance.

## Fixed

- Added automatic database support for `album_genres`, `album_styles`, and `album_moods` in `master_tracks`, including cache refresh persistence and readback helpers.
- Extended the media-server master-track refresh so album metadata is captured and attached to tracks, with Plex album genres, styles, and moods now flowing into Curatorr's filtering pipeline.
- Updated imported-playlist prefill and detected-content handling so album metadata suggestions are preserved separately from track genres and moods.
- Updated smart-playlist preview/build logic so album-level metadata filters are honored consistently instead of being ignored by the playlist engine.
- Added a new weekly listening-report API to drive the report's week-over-week play chart.
- Refined the Overview page to keep longer-view analytics like the 52-week activity heatmap on Overview while the denser listening-report views live on the dedicated Report page.
- Fixed a Listening Report template/runtime issue that could cause `/report` to fail instead of rendering the report.
- Added regression coverage for the new album metadata flow and related auth/release-path behaviors.

## Upgrade Notes

- No manual migration is required for this release.
- Curatorr will add the new `master_tracks` album metadata columns automatically on startup.
- To populate the new album genre/style/mood filters for existing libraries, run a Master Track Cache Refresh after upgrading.
- Last.fm artist tags remain a separate source from media-server metadata, and the wizard now reflects that split more explicitly.
