# Curatorr v0.1.109 Announcement

Curatorr `v0.1.109` adds combined playlists, password sign-in for Plex accounts, and a tidier Jobs page.

## Highlights

- **Combined playlists**: build one playlist from two or more of your playlists, such as newest tracks plus most played, sorted like any other playlist.
- **Password sign-in for Plex accounts**: a fallback for networks that block Plex sign-in, opening the same account and role.
- **Jobs, grouped**: jobs are grouped by purpose, with Run all and Run group to run them one at a time.
