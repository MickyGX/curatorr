# Curatorr Release Announcement

Curatorr `0.1.58` is out.

Highlights:

- **Analyzer throttling controls** — new Settings fields let you set chunk size, delay between chunks, and delay between tracks so the analyzer doesn't monopolise CPU or memory on low-spec or shared NAS hardware.
- **Analyzer now runs at lower CPU priority** — `os.nice(10)` is called at startup so the OS deprioritises the analyzer relative to interactive processes, with no configuration needed.
- **Docker Compose resource limit examples** — `docker-compose.yml` now includes commented-out `cpus` and `mem_limit` entries for the analyzer service for users who want hard caps.
