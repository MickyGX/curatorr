# Curatorr v0.1.94 Announcement

Curatorr `v0.1.94` is out with safer Plex playlist syncs, cleaner master-track refreshes, and a Lidarr monitoring payload fix.

## Highlights

- **Plex playlist writes are now verified** - Curatorr reads generated playlists back after sync and warns if Plex silently drops stale rating keys.
- **Stale Plex keys are pruned after refresh** - refreshed libraries now shed dead master-track cache rows so future smart playlists stop requesting missing items.
- **Lidarr monitoring modes behave cleanly** - Curatorr keeps unsupported values out of Lidarr's `monitorNewItems` field while preserving the selected add behavior.
