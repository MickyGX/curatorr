# Curatorr Release Announcement

Curatorr `0.1.65` is out.

## Highlights

- **Random Library Mix is now in the playlist wizard** with daily random 50-track sampling, one track per artist, and one track per album.
- **Decades are now Curatorr-generated filters** based on track years/release dates, including `2020s`, and are separate from Last.fm Tags.
- **Job startup and Last.fm stats rebuilds are cleaner**: scheduled jobs no longer all run on container boot, setup records the first master refresh through Jobs, and zero-duration Last.fm scrobbles replay as plays.
